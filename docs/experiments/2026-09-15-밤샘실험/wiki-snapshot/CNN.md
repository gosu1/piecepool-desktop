# CNN

> 이미지 처리에 사용되는 [[신경망]] 구조로, 필터 크기와 배치 방식을 통해 효율적인 특징 추출을 수행한다. 최근에는 큰 필터 대신 3x3 필터를 여러 번 쌓는 방식을 주로 사용한다.

## 핵심 개념

이미지 전체에 같은 필터를 공유하여 파라미터 수를 줄인다. 필터 하나가 이미지의 특징 하나를 담당한다. [[트랜스포머]]의 어텐션과 달리 고정된 이웃을 참조하는 특징이 있다.

## 주요 기법

padding(출력 크기 유지), stride(필터 이동 간격), dilation(필터에 구멍을 뚫어 넓은 범위 참조), pooling(다운샘플링) 등이 있다.

## 이해하지 못한 점

1x1 필터의 구체적인 활용 목적이 불분명하다. dilation 기법 사용 시 필터 중간에 빠진 픽셀을 어떻게 처리하는지 헷갈린다.

## 필터 구성

3x3 필터를 두 번 쌓는 것이 5x5 필터 하나를 사용하는 것보다 파라미터 수가 적어 효율적이다. 또한 중간에 [[활성함수]]가 추가되어 비선형성이 증가한다.

## Dilation

필터 원소 사이에 간격을 두어 파라미터 수 증가 없이 수용 영역(receptive field)을 넓히는 기법이다. 주로 세그멘테이션 작업에서 사용되며, 해상도를 높여 작은 객체 검출 성능을 개선하는 데 활용되기도 한다.

## 1x1 컨볼루션

공간 정보는 유지하면서 채널 방향으로 정보를 섞어 채널 수를 줄이는 데 사용한다. 계산량을 줄이기 위한 bottleneck 구조의 핵심 요소다.

## ResNet

층을 깊게 쌓을 때 발생하는 성능 저하 문제를 skip connection으로 해결한다. 입력을 출력에 직접 더해줌으로써 잔차(residual)를 학습한다.
