# 정규화

> 테이블을 분리하여 데이터 중복과 이상 현상을 제거하는 과정이다. 실무에서는 성능을 위해 의도적으로 반정규화를 수행하기도 한다.

## 개념

테이블을 쪼개어 중복과 이상 현상을 없애는 작업이다. [[데이터베이스]] 설계 시 기준을 잡기 위해 필수적이며, 너무 쪼개면 조인 연산으로 인해 성능이 저하될 수 있어 실무에서는 반정규화를 병행하기도 한다.

## 이상 현상

데이터 중복으로 인해 발생하는 문제들이다. 삽입 이상(데이터 입력 불가), 갱신 이상(일관성 유지 어려움), 삭제 이상(원치 않는 데이터 손실)이 있다.

## 정규형 단계

1NF(원자값), 2NF(부분 종속 제거), 3NF(이행 종속 제거), BCNF(모든 결정자가 후보키)로 나뉜다. 2NF는 키의 일부에 종속된 경우를, 3NF는 키가 아닌 속성 간의 종속을 다룬다.

## 학습 기록

2NF와 3NF의 차이점과 BCNF의 예제(수강, 교수, 과목)를 이해하는 데 어려움을 겪었다. [[도서관 좌석 알림 앱]] 개발 시 좌석 테이블의 건물 정보를 별도 테이블로 분리하는 등 실무 적용을 고려 중이다.
