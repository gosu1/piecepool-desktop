# 신경망

> 입력에 가중치를 곱하고 [[활성함수]]를 통과시키는 퍼셉트론을 쌓아 만든 구조다. 은닉층이 2개 이상일 때 심층 신경망(DNN)이라 부른다.

## 구조

퍼셉트론은 입력에 가중치를 곱해 더한 뒤 [[활성함수]]를 통과시킨다. 이 층을 여러 개 쌓으면 심층 신경망(DNN)이 된다.

## 과제

2층 신경망을 numpy로 구현해야 한다.
