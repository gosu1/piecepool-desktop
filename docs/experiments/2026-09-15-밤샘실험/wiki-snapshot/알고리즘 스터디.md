# 알고리즘 스터디

> 알고리즘 문제 풀이를 함께 공부하는 모임. [[DP]]와 그리디 등을 다룬다.

## 운영 방식

매주 백준 3문제를 풀어오고 서로 설명한다. 태윤 선배가 리드하며 목요일 7시에 동아리방에서 진행한다. 2회차에서는 DP 문제를 다루었다.

## 학습 내용

그래프 탐색(BFS/DFS)과 DP를 다룬다. DP 문제에서 점화식을 세우는 데 어려움을 겪고 있다.

## DP

[[DP]] 문제를 풀며 상태 정의의 어려움을 겪고 있다. 1463번과 11726번은 해결했으나, 2579번 계단 오르기 문제에서 상태를 정의하는 데 막혔다. 하은의 설명을 통해 마지막 계단을 밟는 경우를 나누어 점화식을 세우는 법을 이해했다.
