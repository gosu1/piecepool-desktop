# 트랜스포머

> 어텐션 메커니즘을 기반으로 시퀀스를 병렬로 처리하는 모델. 인코더와 디코더 구조로 이루어져 있다.

## 핵심 아이디어

RNN과 달리 순차적 처리가 필요 없어 병렬화가 가능하며, 어텐션을 통해 멀리 있는 단어 간의 관계도 효과적으로 파악한다. 논문 제목은 'Attention Is All You Need'이다.

RNN의 순차적 처리 문제를 해결하기 위해 어텐션만으로 시퀀스를 처리하여 병렬 계산을 가능하게 한다.

## 어텐션

Query, Key, Value 세 요소를 사용하여 Q와 K의 내적으로 유사도를 구하고, 이를 가중치로 V를 가중합한다. 검색 시스템의 질의, 색인, 내용에 비유되지만 아직 개념이 완전히 잡히지 않았다.

## 셀프 어텐션

입력 데이터 하나에서 Q, K, V를 모두 생성하여 문장 내 단어들이 서로를 참조하게 한다. [[CNN]]의 필터가 고정된 이웃만 보는 것과 달리, 데이터마다 가중치를 다르게 생성하여 전체를 본다.

입력에 가중치를 곱해 Q, K, V 행렬을 생성한다. 점수는 Q와 K의 내적을 차원의 제곱근으로 나눈 뒤 소프트맥스를 적용하여 계산하며, 이를 V에 곱한다.

## 멀티헤드 어텐션

어텐션을 여러 개 병렬로 수행하여 합치는 방식이다. 보통 8개의 헤드를 사용하여 서로 다른 관계를 포착한다.

## 위치 인코딩

어텐션은 데이터의 순서를 알지 못하므로 sin/cos 함수 등을 이용해 위치 정보를 별도로 더해준다.

순서 정보가 없는 모델의 한계를 극복하기 위해 sin, cos 함수를 사용하여 위치 정보를 더해준다.

## 인코더-디코더 구조

인코더가 입력을 읽고 디코더가 출력을 생성한다. 디코더는 뒤쪽 정보를 보지 못하도록 masked 어텐션을 사용한다. 디코더의 상세 구조는 추가 학습이 필요하다. 객체 검출 모델인 [[DETR]]은 이 구조를 활용하되 순서가 없는 집합을 다루기 위해 masked 어텐션을 사용하지 않는다.

## 디코더

인코더와 유사하지만 두 가지 차이가 있다. 첫 번째는 학습 시 정답을 가리는 masked 어텐션이며, 두 번째는 인코더 출력을 K, V로 사용하는 cross attention이다. [[DETR]]은 이 구조에서 masked 어텐션을 제거하여 사용한다.
