# DETR

> [[트랜스포머]] 인코더-디코더 구조를 활용하여 객체 검출을 집합 예측 문제로 해결하는 모델이다. 앵커박스나 NMS 같은 수동 부품을 제거하고 bipartite matching을 통해 객체를 검출한다.

## 핵심 아이디어

기존 객체 검출 모델들이 사용하는 앵커박스나 NMS 같은 수동 부품을 제거하고, [[트랜스포머]] 인코더-디코더를 사용하여 객체 검출을 집합 예측 문제로 변환한다.

## 구조

[[CNN]] 백본으로 [[ResNet]]을 사용하며, 마지막 층의 특징을 [[트랜스포머]] 인코더에 입력한다. 디코더는 [[트랜스포머]]의 디코더에서 masked 어텐션을 제거한 구조를 사용하며, 입력 자리에 학습된 벡터인 object query 100개를 넣는다. 디코더가 masked 어텐션을 쓰지 않는 이유는 순서를 바꿔도 결과가 같은 permutation-invariant 특성을 가지기 때문이다.

## 학습 및 한계

예측값과 정답을 일대일로 짝짓는 bipartite matching을 위해 헝가리안 알고리즘을 사용한다. 학습에 500 epoch이 소요될 정도로 오래 걸리며, 작은 객체 검출에 약하다. 다만 큰 객체에 대해서는 [[트랜스포머]]의 비지역적(non-local) 연산 덕분에 성능이 뛰어나다.

## 이해하지 못한 점

위치 인코딩에서 sin, cos 함수를 사용하는 구체적인 이유를 이해하지 못했다. 또한, 학습 과정에서 헝가리안 알고리즘을 통한 매칭이 내가 이해한 방식이 맞는지 확신이 서지 않는다. object query가 학습되면서 구체적으로 무엇을 배우는지에 대해서도 답변하지 못했다. 추가로 auxiliary loss가 디코더 층마다 어떻게 적용되는지 확인이 필요하다. 마지막으로, 왜 작은 객체 검출 성능이 낮은지, 그리고 이를 개선할 방법은 무엇인지 더 공부해야 한다.
