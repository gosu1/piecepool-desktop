# 노트북

> 현재 4년 된 노트북의 성능 저하로 교체를 고민 중이다. 인턴 합격 여부에 따라 맥북 에어 M4 구매나 기존 노트북 배터리 교체를 결정할 예정이다.

## 교체 고민

현재 사용하는 노트북은 4년이 지나 배터리가 1시간밖에 가지 않고, 딥러닝 학습 시 팬 소음이 심하다. 맥북 에어 M4와 LG 그램 프로 RTX를 후보로 두고 있으나, 딥러닝 학습 환경과 비용 문제를 고려해 결정을 유보했다. [[자소서]] 작성이 끝나 [[부산 여행]]에는 가져가지 않는다.

## 딥러닝 환경

[[지훈]]과 [[수아]]는 맥북을 사용하며, 딥러닝 학습은 별도의 데스크탑이나 코랩을 활용한다. 캡스톤 프로젝트는 서버를 이용하므로 노트북에 반드시 CUDA가 필요한지 고민 중이다.
