# 프로세스

> 실행 중인 프로그램을 의미하며, 메모리에 적재된 상태이다. PCB 구조체에 프로세스 정보를 관리한다.

## 상태

프로세스는 new, ready, running, waiting, terminated 상태를 가진다. ready는 CPU 할당을 기다리는 상태이고, waiting은 입출력 등 외부 이벤트를 기다리는 상태이다.

## 생성

fork() 함수를 통해 프로세스를 복제하여 부모-자식 관계를 생성한다. [[스레드]] 생성보다 무겁다.
