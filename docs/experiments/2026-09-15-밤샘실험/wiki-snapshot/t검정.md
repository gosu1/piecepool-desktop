# t검정

> 두 집단의 평균을 비교하는 통계적 검정 방법이다. 표본이 30개 미만일 때 정규분포 대신 t분포를 사용한다.

## 방법

두 집단의 평균을 비교하며, 표본이 30개 미만일 때는 자유도 n-1인 t분포를 활용한다. 파이썬의 scipy.stats.ttest_ind 함수를 사용할 수 있다. 또한 [[단순 선형 회귀]]에서 기울기 b가 0인지 검정할 때도 사용된다.

## 적용 고민

[[달리기]]를 시작한 후 [[수면]]의 질이 좋아졌는지 검정하고 싶으나, 표본이 나 하나뿐이라 적용이 어렵다고 생각했다. 통계 과제 3을 위해 [[커피]] 지출과 [[수면]] 시간 데이터를 활용한 회귀 분석을 고려 중이다.
