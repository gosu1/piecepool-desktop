# CPU 스케줄링

> ready 큐에 있는 [[프로세스]] 중 CPU를 할당할 대상을 결정하는 방법이다. CPU 이용률, 처리량, 대기 시간, 응답 시간, 반환 시간을 기준으로 평가하며 알고리즘마다 트레이드오프가 존재한다.

## 알고리즘

- FCFS: 온 순서대로 처리한다. 긴 작업이 먼저 오면 뒤의 작업들이 기다리는 convoy effect가 발생한다.
- SJF: 짧은 작업부터 처리하여 대기 시간을 최소화한다. 다음 CPU 버스트를 예측해야 하는 실무적 어려움이 있다.
- 우선순위: 우선순위가 낮은 [[프로세스]]가 영원히 CPU를 받지 못하는 starvation 문제가 발생할 수 있으며, aging으로 해결한다.
- 라운드 로빈: 시간 조각(time quantum) 단위로 돌아가며 실행한다. 너무 짧으면 [[컨텍스트 스위치]] 비용이 커진다.
