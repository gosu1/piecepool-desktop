# 활성함수

> [[신경망]]에서 비선형성을 부여하는 함수다. 선형 연산만 쌓으면 결국 하나의 선형 연산과 같아지기 때문에 필요하다.

## 종류

sigmoid는 출력을 0~1 사이로 제한하지만 최근에는 잘 쓰이지 않는다. ReLU는 음수를 0으로, 양수는 그대로 출력하여 계산 효율이 좋다. [[CNN]]의 필터 층 사이에도 비선형성을 부여하기 위해 사용된다.

## 이해하지 못한 점

비선형성이 왜 반드시 필요한지 명확히 이해하지 못했다. 또한 [[CNN]]의 ResNet에서 말하는 '잔차를 학습한다'는 개념이 아직 직관적으로 와닿지 않는다.
