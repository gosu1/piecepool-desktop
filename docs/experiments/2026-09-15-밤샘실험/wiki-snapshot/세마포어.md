# 세마포어

> 정수 값을 사용하여 공유 자원에 대한 접근을 제어하는 [[동기화]] 도구이다.

## 작동 원리

wait() 연산으로 값을 줄이고 signal() 연산으로 값을 늘린다. 값이 0이면 wait()에서 대기한다.

## 활용

값이 1보다 크면 동시에 여러 [[스레드]]가 접근할 수 있다. 예를 들어 DB 커넥션 풀 관리에 사용된다.
