# 동기화

> 공유 자원을 여러 [[스레드]]가 동시에 접근할 때 발생하는 문제를 해결하는 방법이다. [[운영체제]]에서 매우 중요한 개념으로 다뤄진다.

## 문제 상황

여러 [[스레드]]가 같은 변수를 동시에 수정하면 결과가 달라지는 레이스 컨디션이 발생한다. 공유 자원을 접근하는 코드 구간을 임계 구역(critical section)이라 한다.

## 해결 조건

상호 배제(mutual exclusion), 진행(progress), 한정 대기(bounded waiting) 세 가지 조건을 만족해야 한다.

## 관련 도구

[[뮤텍스]]와 [[세마포어]]를 사용하여 동기화를 구현한다. 파이썬에서는 `threading.Lock`을 통해 [[뮤텍스]]를 사용할 수 있다.
