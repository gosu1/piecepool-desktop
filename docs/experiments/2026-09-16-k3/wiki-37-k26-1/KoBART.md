# KoBART

> SKT에서 공개한 한국어 BART 기반 생성 모델. 요약 등 한국어 생성 태스크에 쓰인다.

## 토크나이저

허깅페이스 기본 토크나이저와 원래 kobart_tokenizer가 특수 토큰 처리가 달라서, 허깅페이스 토크나이저를 쓰면 문장 앞이 잘린다. 원래 토크나이저를 써야 정확한 재현이 된다.

SKT의 요약 데모는 모델만 공개되어 있고 학습 데이터는 공개되지 않았다.
