# 현우

> 한국어 NLI 모델 성능 문제를 지적했다.

## 특징

한국어 NLI 모델 성능이 낮아서 [[SummaC]] 방식이 영어만큼 효과적이지 않을 수 있다고 지적했다.

한국어 QG(Question Generation) 모델은 쓸 만한 게 없다고 했다. 이로 인해 [[QAGS]] 방향은 접기로 했다.

[[최교수님]]이 GPU 시간을 현우 선배와 조율하라고 하셨다.

2026-09-16에 한글 수사 정규화("세 명" → 3명)에 대해 지적했다.

**2026-09-24 랩미팅:** 숫자 검사는 규칙이면 되는데 "3명"과 "세 명"처럼 표기가 다른 걸 처리해야 한다고 지적했다. 한국어 수사 정규화가 필요하다.

**2026-10-08 랩미팅:** [[exp-007]] 보고에서 "세 명" 정규화를 넣었냐고 물었다. 아직 넣지 않았으며 이번 주에 할 예정이다.
