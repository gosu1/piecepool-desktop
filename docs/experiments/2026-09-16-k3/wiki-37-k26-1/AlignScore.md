# AlignScore

> 사실 일관성을 "정렬(alignment)" 하나의 개념으로 통일하여 NLI·QA·요약 등 7가지 태스크 데이터를 하나의 모델로 학습한 지표. [[SummaC]] 벤치마크에서 SOTA를 기록했다.

## 핵심 아이디어

사실 일관성을 "정렬(alignment)" 하나로 통일하여 본다. NLI·QA·요약·패러프레이즈 등 7가지 태스크 데이터를 전부 "문맥-주장 쌍이 정렬되나"로 바꿔서 하나의 모델을 학습시킨다. 데이터를 470만 쌍 모을 수 있어서 이점이 크다.

## 성능

[[SummaC]] 벤치마크에서 SOTA를 기록했다. [[SummaC]]-Conv보다 좋다.

## 모델 크기

base(125M)도 large 못지않은 성능을 보인다.

## 한국어 적용

한국어 버전을 만들려면 7가지 한국어 데이터가 필요하다. KLUE에 NLI·STS가 있고, KorQuAD로 QA가 있으며, 요약은 AIHub 데이터를 쓸 수 있다. 패러프레이즈 데이터는 없을 수도 있다. 반만 모아도 되는지는 불확실하다.

[[exp-006]]에서 KLUE-NLI, KLUE-STS(임계로 이진화), KorQuAD(질문+답 → 주장 문장으로 변환), AIHub 요약(참조 요약 = 정렬) 4종, 약 40만 쌍으로 학습했다. 원논문 470만의 1/10 규모다. klue/roberta-base를 A6000 하나로 6시간 학습했다. 사람 평가 200개에서 정확도 0.74, 사람 점수와 스피어만 상관 0.41을 기록하여 [[SummaC]]-ZS(0.70, 0.36)보다 조금 낫다. 데이터를 늘리면 더 오를 듯하다. 그러나 숫자 대조는 여전히 못 잡는다. 정렬 데이터에도 숫자 대조가 없으니까.

## 랩 내 상황

[[exp-006]] 후보로 검토 중이다. 그러나 학습 비용이 크다. 랩 GPU는 A6000 두 장인데 [[현우]] 선배가 하나를 쓰고 있다.

2026-09-16에 baseline 재현과 함께 검토했다.
