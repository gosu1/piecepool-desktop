# exp-003

> [[FactCC]]를 한국어에 적용한 실험. 규칙 기반 가짜 데이터로 학습한 모델이 실제 모델 [[환각]]을 잡지 못해 실패했다.

## 목표

[[FactCC]]를 [[KoBART]] 요약 baseline에 붙여 [[환각]] 자동 평가 파이프라인을 구축한다. [[exp-002]]에서 사람 평가로 22% [[환각]] 비율을 확인한 뒤, 다음 단계로 진행한 실험이다.

## 상태

2026-09-08에 결과 확인 완료. 규칙 기반 가짜 데이터 학습 방식이 실제 모델 [[환각]]을 잡지 못함을 확인했다.

## 설정

- 모델: klue/roberta-base
- 학습 데이터: 규칙 변형으로 만든 가짜 불일치 2만 쌍
- 변형 규칙: 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사
- epoch: 3

## 결과

가짜 데이터 valid 정확도 0.94. 그러나 [[exp-002]]의 사람 평가 50개에 적용한 결과 **정확도 0.58**으로, 거의 동전 던지기 수준이었다. 규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 등 미묘한데, 변형 규칙은 너무 티가 났다.

## 교훈

"[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"도 결과다. 규칙 기반 가짜 데이터 학습의 한계를 직접 확인했다.
