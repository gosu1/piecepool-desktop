# exp-002

> [[KoBART]] 요약 baseline 재현 실험. 토크나이저 수정으로 데모 수치와 거의 일치하는 [[ROUGE]]-1 0.50 / ROUGE-L 0.46을 달성했다. 생성 요약 50개의 사람 평가 결과 [[환각]] 비율은 22%였다.

## 목표

[[exp-001]] 의 토크나이저 문제를 고치고 [[KoBART]] 요약 데모 수치를 정확히 재현한다.

## 설정

- 모델: gogamza/kobart-summarization
- 토크나이저: 원래 [[KoBART]] 토크나이저(kobart_tokenizer) 사용. [[exp-001]] 에서 허깅페이스 토크나이저 대신 원래 토크나이저를 써야 정확한 수치가 나오는 것을 확인했다.
- max_len: 512 / 128
- beam: 4

## 결과

[[ROUGE]]-1 0.50 / [[ROUGE]]-L 0.46. 데모(0.52/0.47)와 거의 같아 재현 성공으로 판단했다.

## 환각 분석

생성 요약 50개를 직접 읽어 확인한 결과, 원문에 없는 내용이 들어간 것은 **11개 (22%)**였다.

대부분은 숫자나 날짜가 바뀌는 [[환각#정의|intrinsic]] [[환각]]이었다. 아예 없는 사실을 추가한 [[환각#정의|extrinsic]] [[환각]]은 2개였다.

[[환각#발생률|Maynez 논문의 XSum 70%]]보다 훨씬 낮은데, 이는 XSum이 한 문장 요약이라 [[환각]]이 더 심한 것이고 뉴스 여러 문장 요약은 덜한 것으로 보인다. 그래도 22%면 문제가 있다.

[[교수님]]이 22%면 충분히 문제라고 하셨으며, 숫자 [[환각]]이 많다는 점에 관심을 보이셨다. "그건 한국어 특성인가 뉴스 특성인가?"라고 질문하셨고, 현재는 모르는 상태이다. 영어 뉴스 요약에서도 숫자 환각이 많은지 찾아볼 예정이다.

이 50개가 첫 사람 평가 데이터이며, 스프레드시트에 저장했다.
