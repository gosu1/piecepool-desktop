# LLM-as-judge

> LLM을 평가자로 사용하는 방법. 사람 평가와 0.8 정도의 상관을 보이며, 한국어에서도 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다. 평가 속도가 느려 [[검증 디코딩]]에는 적합하지 않고 평가용으로만 사용한다.

## 특징

사람 평가와 0.8 정도의 상관을 보인다. 한국어에서는 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 한다.

속도가 느려 [[검증 디코딩]]의 [[구조화된 사실 검사 + NLI|NLI 자리]]에 넣기에는 부적합하다. 평가에만 쓸 수 있다.

## 사용 아이디어

사람 평가 200개에 붙여서 상관을 재면 논문에 한 절이 더 생긴다. 200개면 API 비용이 얼마 안 든다.
