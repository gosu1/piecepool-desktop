# LLM-as-judge

> LLM을 심판으로 써서 [[환각]] 등을 평가하는 방법. 현업에서 사람 평가와 섞어 쓰며 사람과 0.8 정도 상관한다고 한다. 내 사람 평가 200개에 붙여 상관을 재면 논문에 한 절 더 생긴다.

## 실무 평가

초청 세미나(김OO 박사, 산업체)에서 들은 내용이다. 현업에서는 [[환각]]을 "grounded인가"로 부른다 — RAG에서 검색된 문서에 근거하는가의 의미다. 평가는 사람 + LLM-as-judge를 섞어서 하고, LLM 심판은 사람과 0.8 정도 상관한다고 했다. 질문해서 확인한 바로는 한국어에서의 신뢰도는 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 했다.

## 적용 계획

LLM-as-judge를 내 사람 평가 200개([[한국어 요약의 환각 측정과 완화]])에 붙여서 상관을 재면 논문에 한 절 더 생긴다. API 비용은 200개면 얼마 안 든다. 내 [[검증 디코딩]]([[exp-007]])의 NLI 자리에 LLM 심판을 넣는 생각도 했지만 느려서 안 될 것 같고, 평가에만 쓰는 게 맞다.
