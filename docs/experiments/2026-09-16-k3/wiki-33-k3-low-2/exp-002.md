# exp-002

> [[한국어 요약의 환각 측정과 완화]]의 두 번째 실험. [[exp-001]]의 토크나이저 문제를 고쳐 [[KoBART]] 요약 데모 수치 재현에 성공했고, 생성 요약 50개를 직접 읽어 [[환각]] 비율 22%를 쟀다.

## 설정과 결과

[[exp-001]]의 토크나이저 문제를 고쳐서 다시 돌렸다. 결과는 [[ROUGE]]-1 0.50, [[ROUGE]]-L 0.46으로 데모(0.52 / 0.47)와 거의 같아 재현 성공으로 봤다.

## 환각 비율 측정

생성 요약 50개를 직접 읽고 [[환각]]을 확인했다. 원문에 없는 내용이 들어간 것이 11개(22%)였다. 대부분 숫자나 날짜가 바뀐 intrinsic이고, 아예 없는 사실을 추가한 것은 2개였다. Maynez 논문의 XSum 70%보다 훨씬 낮은데, XSum이 한 문장 요약이라 더 심하고 뉴스 여러 문장 요약은 덜한 것으로 보인다. 그래도 22%면 문제다. 이 50개가 첫 사람 평가 데이터이며 스프레드시트에 저장했다.
