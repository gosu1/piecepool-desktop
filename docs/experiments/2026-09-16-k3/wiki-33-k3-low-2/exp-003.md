# exp-003

> [[한국어 요약의 환각 측정과 완화]]의 세 번째 실험. [[FactCC]] 변형 규칙을 한국어로 옮겨 가짜 데이터 2만 쌍으로 klue/roberta-base를 학습시켰으나, [[exp-002]]의 사람 평가 50개에서 정확도 0.58로 사실상 실패했다.

## 진행

[[FactCC]] 변형 규칙을 한국어로 옮겼다. 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사 네 가지다. 이 규칙으로 가짜 데이터 2만 쌍을 만들어 klue/roberta-base 이진 분류를 3 epoch 학습시켰다.

가짜 데이터 valid 정확도는 0.94로 좋아 보였으나, [[exp-002]]의 사람 평가 50개에 적용하니 정확도 0.58로 거의 동전 던지기 수준이었다. 규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 식인데 내 변형은 너무 티가 났다. "[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"도 결과라고 정리했다. 다음은 학습 없이 NLI만 쓰는 [[SummaC]] ([[exp-004]])다.
