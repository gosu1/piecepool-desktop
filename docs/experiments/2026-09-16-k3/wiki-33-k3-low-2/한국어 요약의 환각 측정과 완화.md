# 한국어 요약의 환각 측정과 완화

> 이번 학기 랩미팅에서 발표한 주제. 한국어 요약에서 [[환각]]이 얼마나 나오는지 재고 완화하는 것이 목표다.

## 교수님 코멘트

영어 결과가 한국어에서 그대로 될 거라고 가정하지 말 것. 안 되는 걸 보이는 것도 결과다. 지표 논문만 읽지 말고 빨리 baseline을 돌려서 [[환각]]이 실제로 얼마나 나오는지 볼 것. 사람 평가 없이는 지표를 믿을 수 없으므로 처음부터 사람 평가 데이터를 만들어야 한다.

## 할 일

남은 것: [[현우]] 선배가 다시 확인한 한글 수사 정규화("세 명" → 3명)를 이번 주에 넣기, [[교수님]]이 물은 영어 뉴스 요약의 숫자 [[환각]] 비율 찾기, 사람 평가 가이드라인을 논문 부록에 넣기(24일 랩미팅 지시), 세미나에서 나온 [[LLM-as-judge]] 200개 상관(API 비용 문제), 논문 초안 4쪽(10월 20일까지), [[소연]]이에게 영어 교정 부탁, AIHub 라이선스 출처 표기 확인.

## 진행 상황

첫 baseline 실험 [[exp-001]]을 돌렸다. [[KoBART]] 요약 데모 재현을 시도했으나 토크나이저 문제로 [[ROUGE]]가 데모 수치보다 한참 낮게 나왔다. [[exp-002]]에서 토크나이저를 고쳐 재현에 성공했고([[ROUGE]]-1 0.50 / [[ROUGE]]-L 0.46), 생성 요약 50개를 직접 읽어 [[환각]] 비율 22%를 쟀다. [[FactCC]]를 [[exp-003]]에서 한국어에 적용했으나 사람 평가 50개에서 정확도 0.58로 사실상 실패했다. "[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"도 결과다. QA 기반 지표 [[QAGS]]와 [[QuestEval]]도 읽었으나 한국어 QG 모델은 쓸 만한 게 없어 이 방향은 접었다. [[exp-004]]에서 klue/roberta-large-nli로 [[SummaC]]-ZS를 한국어에 적용해 정확도 0.72를 얻었고 숫자 [[환각]]을 잘 못 잡는 약점을 확인했다. [[exp-005]]에서 사람 평가를 200개로 늘리고 [[소연]]이 100개를 같이 봐 동의율 kappa 0.71을 얻었다. [[환각]] 비율은 23.5%로 50개 때와 비슷했고, 그중 숫자·날짜 변경이 62%였다. 논문에서는 '원문에서 추론 가능하면 [[환각]] 아님'으로 정의를 두고 가이드라인에 예시를 적기로 했다. [[exp-006]]에서는 한국어 정렬 데이터 4종 약 40만 쌍으로 한국어 [[AlignScore]]를 학습해 정확도 0.74, 상관 0.41로 [[SummaC]]-ZS보다 조금 나았다. [[exp-007]] [[검증 디코딩]]으로 빔 4개 후보를 문장 단위 NLI + 숫자 규칙으로 재정렬해 [[환각]] 비율을 23.5%에서 14.0%로 낮췄고, 속도는 배치로 묶어 5배에서 1.75배로 줄였다.

10월 8일 랩미팅에서 [[exp-007]]을 보고하자 [[교수님]]이 "학회 내자"고 해 [[학회 투고]]가 확정됐다. 구성은 서론(지표는 사람 평가와 맞아야 의미) → 사람 평가 200개 + 가이드라인 + kappa → 발견(숫자 [[환각]] 62%) → 지표 비교([[FactCC]] 실패, [[SummaC]] 0.70, [[AlignScore]] 0.74) → [[검증 디코딩]](14.0%) → 한계(200개, 뉴스만, 속도)다. [[교수님]]은 실패한 [[FactCC]] 결과도 넣으라고 했다 — 남이 같은 삽질 안 하게. 이번 학기 처음으로 잘 되는 느낌이다.

## 졸업 계획

졸업은 남년 6월. 학회 논문 하나(워크숍 급이면 된다)와 졸업논문이 필요하다. [[교수님]]과의 면담에서 주제를 측정과 완화 둘 다가 아니라 하나로 좁혔고, 순서는 측정 → 완화, 학회 논문은 완화 쪽으로 내기로 했다. [[학회 투고]]처는 [[교수님]] 추천대로 EMNLP 신뢰성 워크숍(11월 1일 마감, 4쪽, 영어)으로 정했고, 마감까지 6주라 실험은 3주 안에 끝내야 한다. 4쪽 구성은 발견 하나 + 방법 하나 + 표 두 개이고 지표 비교는 표 하나로 압축한다. 학회 다음으로는 [[구조화된 사실 검사 + NLI]](숫자·날짜·고유명사는 규칙, 나머지는 NLI)를 졸업논문 chapter로 할 생각이다.
