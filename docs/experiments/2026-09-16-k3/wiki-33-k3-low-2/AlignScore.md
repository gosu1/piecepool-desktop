# AlignScore

> Zha et al. 2023의 사실 일관성 평가 모델. NLI, QA, 요약 등 7가지 태스크 데이터를 전부 '문맥-주장 쌍이 정렬되나'로 통일해 하나의 모델을 학습했고, [[SummaC]] Benchmark에서 SOTA를 찍었다.

## 방법

NLI, QA, 요약, 패러프레이즈 등 7가지 태스크 데이터를 전부 '문맥-주장 쌍이 정렬되나'라는 하나의 형식으로 바꿔서 하나의 모델을 학습한다. 학습 데이터는 470만 쌍이다. 아이디어는 '사실 일관성 = 정렬' 하나로 보는 것이다. [[SummaC]] Benchmark에서 SOTA였고 [[SummaC]]-Conv보다 좋았다. 데이터를 많이 모을 수 있어서 이긴 것으로 보인다. 모델 크기는 base(125M)도 large 못지않다고 한다.

## 한국어 적용 검토

한국어 버전을 만들려면 7가지 태스크의 한국어 데이터가 필요하다. KLUE에 NLI와 STS가 있고, KorQuAD에 QA가 있고, 요약은 AIHub에 있다. 패러프레이즈는 없을 수도 있고, 반만 모아도 되는지는 모르겠다. 랩 GPU가 A6000 두 장인데 [[현우]] 선배가 하나를 쓰고 있다. 다행히 base(125M)도 large 못지않다고 해서 부담이 줄었다. 24일 랩미팅에서 [[교수님]]은 AlignScore는 합병되 안 돼도 되며 본론은 줄이는 쪽이라고 했다. [[exp-006]]에서 실제로 돌렸다 — 4종 데이터(KLUE-NLI, KLUE-STS, KorQuAD, AIHub 요약) 약 40만 쌍(원논문의 1/10)으로 klue/roberta-base를 학습해 사람 평가 200개 정확도 0.74, 상관 0.41로 [[SummaC]]-ZS보다 조금 나았다. 데이터를 늘리면 더 오를 듯한데 숫자 대조는 여전히 못 잡는다.
