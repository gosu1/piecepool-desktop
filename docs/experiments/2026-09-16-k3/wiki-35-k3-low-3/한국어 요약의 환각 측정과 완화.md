# 한국어 요약의 환각 측정과 완화

> 랩미팅에서 발표한 연구 주제. 한국어 요약의 [[환각]]을 측정하고 완화하는 것이 목표다.

## 방향

[[환각]] 을 한국어 요약에서 측정하고 완화하는 연구. [[최교수님]] 은 영어 결과가 한국어에서 그대로 될 거라고 가정하지 말고, 빨리 baseline 을 돌려 [[환각]]이 실제로 얼마나 나오는지 볼 것, 그리고 처음부터 사람 평가 데이터를 만들 것을 조언했다.

9월 면담에서 주제를 좁혔다. 측정과 완화를 둘 다 하면 얕아지므로, 순서는 측정 → 완화로 하되 학회 논문은 완화 쪽으로 낸다. 측정은 완화를 위한 도구다.

## 다음 할 일

완료한 것: baseline 재현, 사람 평가 200개, [[SummaC]] / [[AlignScore]] 평가, [[exp-007]] [[검증 디코딩]]([[환각]] 23.5% → 14.0%), [[exp-004]]·[[exp-005]] 랩미팅 보고, [[학회 논문 초안]] 개요 잡기, [[검증 디코딩]] 속도 줄이기 — 첫 실행은 1000개 기준 4분이 21분으로 5배였는데 배치로 묶어 1.75배로 줄였다. 남은 것: 한글 수사 정규화("세 명" → 3명) — [[현우]] 선배가 8일 랩미팅에서 넣었냐고 물었고 아직이라 이번 주에 한다. 평가 가이드라인을 논문 부록에 넣기 — [[최교수님]] 지시. 실패한 [[FactCC]] 결과를 논문에 넣기 — [[최교수님]]이 "남이 같은 삽질 안 하게" 넣으라고 했다. 영어 뉴스 요약의 숫자 [[환각]] 비율 찾기 — [[최교수님]]이 "숫자 [[환각]]이 한국어 특성인가 뉴스 특성인가"라고 물은 데서 나온 과제이고, 초안에 비교 근거가 빠져 있다. 다만 세미나에서 숫자·날짜·고유명사가 [[환각]]의 대부분이라는 얘기를 들어 뉴스 특성이 아니라 일반적인 현상일 수도 있다는 생각이 들었다. [[LLM-as-judge]] 200개와 사람 평가의 상관 — 세미나에서 나온 아이디어인데 API 비용이 든다(200개면 얼마 안 든다). 성공하면 논문에 한 절이 더 생긴다. [[검증 디코딩]]의 NLI 자리에 LLM 심판을 넣는 것은 느려서 안 하기로 했다. 논문 초안 4쪽은 10월 20일까지다. [[소연]]에게 영어 교정을 부탁한다. [[소연]]이 주제(한국어 대화 요약)와 데이터 공유를 교수님이 허락했다. AIHub 라이선스 출처 표기도 확인해야 한다.

지표 실험은 [[exp-006]]까지로 마무리한다 — 교수님이 "지표는 여기까지. 이제 줄이는 것만"이라며 [[exp-007]]에 집중하라고 했다. 8일 랩미팅에서 [[exp-007]] 결과(14.0%, 속도 1.75배)를 보고했고 교수님이 "학회 내자"고 했다 — 11월 1일 마감, 워크숍 4쪽이다. 학습 기반 완화([[RLHF 환각 줄이기]], Roit et al. 2023)는 PPO 안정화가 어렵고 랩 GPU로 무리라, 추론 시점 방법으로 먼저 결과를 내고 학습 방법은 후속으로 미룬다.

논문 관련 연구 절 구성: Maynez(정의) → [[FactCC]]/[[SummaC]]/[[AlignScore]](지표) → [[CLIFF]]/[[검증 디코딩]](줄이기, 추론) → [[RLHF 환각 줄이기]](줄이기, 학습).

[[학회 투고]] 는 교수님 추천으로 EMNLP 워크숍(신뢰성, 11월 1일 마감, 4쪽)으로 정했고, 8일 랩미팅에서 투고가 확정됐다. 4쪽에는 발견 하나 + 방법 하나 + 표 두 개를 넣고 지표 비교는 표 하나로 압축한다.
