# LLM-as-judge

> LLM을 심판으로 써서 요약의 사실 일관성을 평가하는 방법. 사람 평가와 0.8 정도 상관하고, GPT-4급이면 한국어에서도 쓸 만하다고 한다.

## 세미나에서 들은 것

김OO 박사의 세미나 "LLM 신뢰성 평가 실무"에서 나온 내용. 현업에서는 평가를 사람 + LLM-as-judge를 섞어서 하고, LLM 심판은 사람과 0.8 정도 상관한다고 했다. 내가 질문한 한국어 신뢰도에 대해서는 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 답했다.

## 내 연구와의 관계

LLM-as-judge를 [[한국어 요약의 환각 측정과 완화]]의 사람 평가 200개에 붙여서 상관을 재면 논문에 한 절이 더 생긴다. API 비용이 들지만 200개면 얼마 안 든다. 내 [[검증 디코딩]]([[exp-007]])의 NLI 자리에 LLM 심판을 넣는 것은 느려서 안 될 것 같고, 평가에만 쓰는 게 맞다.
