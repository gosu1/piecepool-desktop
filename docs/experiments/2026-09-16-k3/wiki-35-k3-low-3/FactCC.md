# FactCC

> Kryscinski et al. 2020 의 사실 일관성 분류기. 규칙으로 원문을 변형해 가짜 불일치 데이터를 만들고 BERT 이진 분류기를 학습시킨다. 한국어 적용에는 규칙을 다시 짜야 한다.

## 방법

원문 문장을 규칙으로 변형해서(개체 바꾸기, 숫자 바꾸기, 부정 넣기, 대명사 바꾸기) 가짜 불일치 데이터를 만든다. 그걸로 BERT 를 학습시켜 요약 문장이 원문과 일치하는지 이진 분류한다. 사람 평가 데이터에서 기존 지표보다 잘 맞았다.

## 한국어 적용

변형 규칙이 영어 기준이라 한국어에는 그대로 못 쓴다. 조사가 있어서 개체 바꾸기가 안 된다 — "철수가" → "영희가"는 되는데 "철수는" → "영희는"처럼 조사를 맞춰야 해서 규칙을 다시 짜야 한다. 이후 논문들은 규칙으로 만든 가짜 불일치가 실제 모델의 [[환각]] 과 다르다고 비판했다 — 모델은 규칙 변형보다 미묘하게 틀린다.

[[exp-003]]에서 규칙을 한국어로 다시 짜서(개체·숫자·부정·대명사) 가짜 데이터 2만 쌍으로 klue/roberta-base 분류기를 학습했다. 가짜 데이터 valid 정확도는 0.94였지만 [[exp-002 baseline 재현]]의 사람 평가 50개에서는 정확도 0.58로 거의 동전 던지기였다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 식인데 규칙 변형은 너무 티가 났고, "규칙 변형과 실제 [[환각]]이 다르다"는 비판이 맞았다. FactCC 스타일은 한국어 뉴스 요약에서 안 된다는 결론을 낸다.

## 다음 할 일

[[exp-003]]에서 한국어 적용을 핵 봤고 사람 평가 정확도 0.58로 실패해 이 방향은 접는다. 다만 [[최교수님]]이 안 되는 이유를 논문에 적고 실패도 표로 넣으라고 했다. 다음 지표는 [[SummaC]] ([[exp-004]])로, 학습 없이 NLI만 쓰므로 규칙 변형 문제가 없다.
