# exp-003

> [[FactCC]] 를 한국어에 적용한 세 번째 실험. 규칙 변형 가짜 데이터 2만 쌍으로 klue/roberta-base 분류기를 학습해 가짜 데이터 valid 정확도 0.94를 얻었지만, [[exp-002 baseline 재현]]의 사람 평가 50개에서는 정확도 0.58로 실패했다. [[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다는 결론을 내리고 다음은 [[SummaC]] ([[exp-004]])로 넘어간다.

## 진행 상황

[[FactCC]] 를 붙이는 실험이다. 학습을 돌려놓고 기다리는 중이며 아직 결과가 나오지 않았다. 하루 종일 이 실험을 했다.

## 설정

[[FactCC]] 변형 규칙을 한국어로 다시 짰다 — 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사. 이 규칙으로 가짜 데이터 2만 쌍을 만들어 klue/roberta-base 이진 분류기를 3 epoch 학습했다.

## 결과

가짜 데이터 valid 정확도는 0.94로 좋아 보였다. 그러나 [[exp-002 baseline 재현]]의 사람 평가 50개에 적용하니 정확도 0.58로 거의 동전 던지기였다.

## 해석

규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 식인데, 규칙 변형은 너무 티가 났다. 한 시간 낙담했지만 "[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"는 것도 결과다 — [[최교수님]]이 안 되는 걸 보이는 것도 결과라고 한 것과 맞닿는다. 다음은 [[SummaC]] ([[exp-004]])로, 학습 없이 NLI만 쓰므로 이 문제가 없다.
