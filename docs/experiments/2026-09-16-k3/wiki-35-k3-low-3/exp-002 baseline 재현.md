# exp-002 baseline 재현

> [[exp-001 KoBART 재현]]의 토크나이저 문제를 고쳐 baseline 재현에 성공한 실험. [[ROUGE]]가 데모와 거의 같게 나왔고, 생성 요약 50개 사람 평가에서 [[환각]] 22%를 확인했다. 이 50개가 첫 사람 평가 데이터다.

## 설정과 결과

[[exp-001 KoBART 재현]]에서 발견한 토크나이저 문제를 고쳐 다시 돌렸다. [[ROUGE]]-1 0.50 / [[ROUGE]]-L 0.46으로 데모(0.52 / 0.47)와 거의 같아 재현 성공으로 봤다. [[한국어 요약의 환각 측정과 완화]]의 baseline 재현이 완료되었다.

## 환각 사람 평가

생성 요약 50개를 직접 읽고 확인했더니 원문에 없는 내용이 들어간 것이 11개(22%)였다. 대부분 숫자나 날짜가 바뀐 intrinsic [[환각]]이고, 아예 없는 사실 추가(extrinsic)는 2개였다. [[On Faithfulness and Factuality in Abstractive Summarization]]의 70%보다 훨씬 낮은데, XSum이 한 문장 요약이라 더 심하고 뉴스 여러 문장 요약은 덜한 듯하다. 그래도 22%면 문제다. 이 50개가 첫 사람 평가 데이터이며 스프레드시트에 저장했다.
