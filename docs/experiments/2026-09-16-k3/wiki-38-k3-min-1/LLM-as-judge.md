# LLM-as-judge

> LLM을 심판으로 써서 요약을 평가하는 방법. 현업에서는 사람 + LLM-as-judge를 섞어 쓰며, 사람과 0.8 정도 상관한다. 사람 평가 200개와의 상관을 재는 것이 다음 실험이다.

## 계획

사람 평가 200개에 LLM-as-judge 점수를 붙여 상관을 재면 논문에 한 절이 더 생긴다. API 비용이 걸림돌이었는데 200개면 얼마 안 들어서 해소됐다. [[한국어 요약 환각 측정과 완화]] 의 지표 후보다. 한편 [[exp-007]] [[검증 디코딩]]의 NLI 자리에 LLM 심판을 넣는 생각도 했으나 느려서 안 될 듯하다 — 평가에만 쓴다.

## 현업에서의 사용

김OO 박사 초청 세미나(2026-09-17)에서 나온 현업 이야기다. 평가는 사람과 LLM-as-judge 를 섞어서 하며, LLM 심판은 사람과 0.8 정도 상관한다. 한국어에서 LLM 심판 신뢰도를 물었더니 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 했다.
