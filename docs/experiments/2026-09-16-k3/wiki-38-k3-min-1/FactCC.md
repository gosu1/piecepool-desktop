# FactCC

> 사실 일관성을 분류기로 재는 지표. 원문 문장을 규칙으로 변형해 가짜 불일치 데이터를 만들고 BERT 이진 분류기를 학습한다.

## 방법

원문 문장을 규칙으로 변형해서(개체 바꾸기, 숫자 바꾸기, 부정 넣기, 대명사 바꾸기) 가짜 불일치 데이터를 만든다. 그걸로 BERT를 학습시켜 "이 요약 문장이 원문과 일치하나" 이진 분류를 한다. 사람 평가 데이터에서 기존 지표보다 잘 맞았다. [[요약 환각]] 을 재는 또 다른 평가 방식이다.

## 한국어 적용 문제

변형 규칙이 영어 기준이다. 한국어는 조사가 있어서 개체 바꾸기가 그대로 안 된다. "철수가" → "영희가"는 되는데 "철수는" → "영희는"처럼 조사를 맞춰야 해서 규칙을 다시 짜야 한다.

## 비판

만든 가짜 불일치가 실제 모델이 내는 환각과 다르다는 비판이 이후 논문들에서 나왔다. 모델은 규칙 변형보다 미묘하게 틀린다.

## 나와의 연결

[[exp-003]] 에서 한국어로 실제로 돌려봤다. 가짜 데이터 2만 쌍으로 klue/roberta-base를 학습해 가짜 데이터 valid 정확도 0.94를 얻었지만, [[exp-002]] 의 사람 평가 50개에서는 0.58로 거의 동전 던지기였다. 규칙 변형이 실제 모델 환각보다 너무 티가 났고, "FactCC 스타일은 한국어 뉴스 요약에서 안 된다"를 직접 확인했다. 다음은 학습 없이 NLI만 쓰는 [[SummaC]] ([[exp-004]])다.

## 관련 연구

[[CLIFF]](Cao & Wang 2021)는 대조 학습으로 환각 있는 요약을 negative로 두고 학습하는데, 데이터 만들기가 FactCC 변형과 비슷하다.
