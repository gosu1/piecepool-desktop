# AlignScore

> 사실 일관성을 "정렬(alignment)" 하나로 통일해 재는 지표. 7가지 태스크 데이터를 문맥-주장 정렬 판별로 바꿔 하나의 모델을 학습하며, [[SummaC]] 벤치마크에서 SOTA다.

## 방법

NLI, QA, 요약, 패러프레이즈 등 7가지 태스크 데이터를 전부 "문맥-주장 쌍이 정렬되나"로 바꿔 하나의 모델을 학습한다. 학습 데이터는 470만 쌍이다. 아이디어는 "사실 일관성 = 정렬" 하나로 보는 것이다. [[SummaC]] 벤치마크에서 SOTA로 [[SummaC]]-Conv보다 좋다. 데이터를 많이 모을 수 있어서 이긴 듯하다. 모델 크기는 base(125M)도 large 못지않다고 한다.

## 한국어 적용

한국어 버전을 만들려면 7가지 태스크의 한국어 데이터가 필요한데, [[exp-006]] 에서 4종을 모아 부분 데이터로 돌렸다: [[KLUE-NLI]], KLUE-STS(임계로 이진화), KorQuAD(질문+답을 주장 문장으로 변환), AIHub 요약(참조 요약 = 정렬)로 약 40만 쌍, 원논문 470만의 1/10이다. klue/roberta-base를 A6000 하나로 6시간 학습해 사람 평가 200개에서 정확도 0.74, 스피어만 상관 0.41로 [[SummaC]]-ZS(0.70, 0.36)보다 조금 나았다. 데이터를 늘리면 더 오를 듯하지만, 숫자 환각은 정렬 데이터에 숫자 대조가 없어 여전히 못 잡는다. 2026-09-24 랩미팅에서 [[최교수님]]은 "핵볼되 안 돼도 된다. 본론은 줄이는 쪽"이라고 하셔서 우선순위는 낮다.
