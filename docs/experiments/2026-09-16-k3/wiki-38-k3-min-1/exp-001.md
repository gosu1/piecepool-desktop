# exp-001

> [[한국어 요약 환각 측정과 완화]] 의 첫 baseline 재현 실험. SKT KoBART 요약 데모 수치 재현을 목표로 했으나 ROUGE가 한참 낮게 나왔고, 원인은 토크나이저였다.

## 설정

gogamza/kobart-summarization 모델, AIHub 뉴스 요약 valid 1000개, max_len 512 / 128, beam 4.

## 결과

ROUGE-1 0.31 / ROUGE-L 0.29. 데모 페이지 수치(0.52 / 0.47)에 한참 못 미쳤다.

## 원인

원인 찾기에 2시간을 썼고, 토크나이저가 문제였다. 허깅페이스 토크나이저 대신 원래 KoBART 토크나이저(kobart_tokenizer)를 써야 한다. 특수 토큰이 다르게 들어가서 문장 앞이 잘렸다.

## 다음

토크나이저를 바꿔 다시 돌렸다. 그것이 [[exp-002]] 이며, ROUGE가 데모 수치와 거의 같게 나와 재현에 성공했다.
