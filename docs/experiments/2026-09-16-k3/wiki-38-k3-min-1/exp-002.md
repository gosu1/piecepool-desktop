# exp-002

> [[한국어 요약 환각 측정과 완화]] 의 baseline 재현 실험. [[exp-001]] 의 토크나이저 문제를 고쳐 데모 수치 재현에 성공했고, 생성 요약 50개를 직접 읽어 환각 비율 22%를 확인했다.

## 결과

[[exp-001]] 의 토크나이저 문제를 고쳐 다시 돌렸다. ROUGE-1 0.50 / ROUGE-L 0.46으로 데모 수치(0.52 / 0.47)와 거의 같아 재현 성공으로 본다.

## 환각 확인

생성 요약 50개를 직접 읽었다. 원문에 없는 내용이 들어간 것이 11개 (22%)였다. 대부분 숫자나 날짜가 바뀐 intrinsic [[요약 환각]] 이고, 아예 없는 사실 추가(extrinsic)는 2개였다. [[Maynez et al. 2020]] 이 XSum에서 본 70%보다 훨씬 낮은데, XSum이 한 문장 요약이라 더 심하고 뉴스 여러 문장 요약은 덜한 듯하다. 2026-09-10 랩미팅에서 [[최교수님]] 도 22%면 충분히 문제라고 하셨고, 숫자 환각이 많다는 점에 관심을 보이며 한국어 특성인지 뉴스 특성인지 물으셨다 — 아직 모르겠고, 영어 뉴스 요약에서도 숫자 환각이 많은지 찾아보기로 했다. 이후 [[exp-005]] 에서 사람 평가를 200개로 늘렸더니 환각 비율 23.5%로 이 22%와 비슷했다.

## 사람 평가 데이터

이 50개가 내 첫 사람 평가 데이터다. 스프레드시트에 저장했다.
