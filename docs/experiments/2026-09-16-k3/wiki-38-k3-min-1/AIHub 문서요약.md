# AIHub 문서요약

> AIHub의 한국어 문서 요약 데이터셋. 30만 건 이상으로 뉴스, 사설, 법률을 포함하고 추출 요약과 생성 요약이 둘 다 있다. 실험에는 뉴스 부분만 쓰기로 했다.

## 구성과 선택

30만 건 이상이며 뉴스, 사설, 법률이 섞여 있다. 추출 요약과 생성 요약이 둘 다 있는데, 생성 요약 레이블은 사람이 쓴 것이라 환각 없는 참조로 쓸 수 있다. 후보 중 뉴스가 제일 묵직해 AIHub 문서요약의 뉴스 부분만 쓰기로 했다. 다른 후보로 AIHub 논문요약(20만, 너무 긺), KoBART 요약 데모(모델만 있음), 사법부 판결요약(적고 전문 용어)이 있었다.

## 레이블 환각 우려

[[소연이]]가 AIHub 레이블 자체에 [[요약 환각]]이 있을 수 있다고 지적했다. 참조 요약이 원문에 없는 말을 하면 그걸 "정답"으로 학습하게 되므로, 표본 50개를 직접 보기로 했다.

## 라이선스

로그인하고 신청해야 하며 연구 목적은 가능하다. 학회 논문에 쓸 때 출처 표기가 필요하다.
