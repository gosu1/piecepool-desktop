# 현우

> 랩 선배. 한국어 NLI 모델 성능 문제로 [[SummaC]] 방식이 한국어에서는 영어만큼 안 될 수 있다는 우려를 했다. GPU 시간을 조율해 함께 쓴다.

## 2026-09-10 랩미팅

한국어 개척명 인식 도메인 적응(법률 문서)으로 발표했다. 내 주제와 직접 관련은 없지만 "도메인 옮기면 다 떨어진다"는 결론이 내 상황(영어 지표를 한국어로 옮기기)과 비슷하다고 느꼈다. 한국어 QG 모델은 쓸 만한 게 없다고 해서 [[QAGS]] 방향은 접기로 했다.

## 한글 수사 정규화 지적

한글 수사 정규화("세 명" → 3명)를 지적해 할 일에 올랐다. [[exp-004]] 에서 확인한 NLI의 숫자 환각 약점과 같은 줄기의 문제다. 2026-09-24 랩미팅에서도 숫자 검사는 규칙이면 되는데 "3명"과 "세 명"처럼 표기가 다른 걸 처리해야 한다고 했다. 맞다 — 한국어 수사 정규화가 숫자 규칙 검사의 전제다. 다만 [[exp-007]] 구현에서는 일단 아라비아 숫자만 처리하기로 했다(2026-10-04).
