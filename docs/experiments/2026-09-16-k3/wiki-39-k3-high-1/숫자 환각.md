# 숫자 환각

> 한국어 뉴스 요약 [[환각]]의 절반 이상(62%)을 차지하는 숫자·날짜 변경 [[환각]]. NLI는 잘 못 잡지만 규칙 검사로는 100% 잡힌다. [[교수님]]이 논문의 '발견'으로 앞세우라고 했다.

## 발견

[[exp-005 사람 평가 파일럿|exp-005]]의 사람 평가 200개에서 [[환각]] 47개 중 숫자·날짜 변경이 29개(62%)였다. 한국어 뉴스 요약 [[환각]]의 절반 이상이 숫자다. 24일 랩미팅에서 [[교수님]]은 이 62%가 논문의 '발견'이라며 앞세우라고 했고, 그러면 핵법(숫자 규칙)이 자연스럽다고 했다. 숫자 환각이 많은 것이 한국어 특성인지 뉴스 특성인지는 아직 모르는데, 산업체 세미나에서도 숫자, 날짜, 고유명사가 환각의 대부분이라는 얘기를 들어 일반적인 현상일 수 있다.

## 측정의 어려움과 핵법

NLI는 숫자가 바뀐 [[환각]]을 잘 못 잡는다. [[exp-004 SummaC|exp-004]]에서 [[SummaC]]-ZS가 "3명 사망"과 "5명 사망"을 entailment 0.6 정도로 줬는데, KLUE-NLI 학습 데이터에 숫자 대조가 적어서인 듯하다. 반면 [[exp-007 검증 디코딩|exp-007]]의 규칙 검사로는 숫자 [[환각]]이 100% 잡힌다. 이것이 [[구조화된 사실 검사 + NLI]]의 규칙 부분에 해당한다. 다만 [[현우]] 선배 지적대로 "3명"과 "세 명"처럼 표기가 다른 경우를 처리하려면 한국어 수사 정규화가 필요하다.

[[exp-007 검증 디코딩|exp-007]] 첫 시도에서 NLI 재정렬에 숫자 규칙을 더한 디코딩은 숫자 [[환각]]을 29개에서 9개로 줄였고, 전체 [[환각]] 감소(23.5% → 14.0%)의 대부분이 이 규칙에서 나왔다. NLI 재정렬만으로는 23.5%가 19.8%로만 낮아졌다.
