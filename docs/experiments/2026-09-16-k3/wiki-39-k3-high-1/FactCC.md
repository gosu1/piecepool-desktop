# FactCC

> Kryscinski et al. 2020의 사실 일관성 분류 지표. 규칙으로 원문을 변형해 가짜 불일치 데이터를 만들어 BERT를 학습시킨다. 한국어 적용 실험([[exp-003 FactCC|exp-003]])에서 사람 평가 데이터 정확도 0.58로 실패해, 규칙 변형과 실제 [[환각]]이 다르다는 비판이 확인되었다.

## 방법

원문 문장을 규칙으로 변형해서(개체 바꾸기, 숫자 바꾸기, 부정 넣기, 대명사 바꾸기) 가짜 불일치 데이터를 만들고, 그것으로 BERT를 학습시켜 "이 요약 문장이 원문과 일치하나"를 이진 분류한다. 사람 평가 데이터에서 기존 지표보다 잘 맞았다. 이 규칙 변형으로 학습 데이터를 만드는 방식은 대조 학습으로 [[환각]]을 줄이는 [[CLIFF]]의 데이터 만들기와도 비슷하다.

## 한국어 적용 문제

변형 규칙이 영어 기준이라 한국어에는 그대로 적용되지 않는다. 한국어는 조사가 있어서 개체 바꾸기가 그대로 안 된다. "철수가" → "영희가"는 되는데 "철수는" → "영희는"처럼 조사를 맞춰야 하므로 규칙을 다시 짜야 한다. 또한 규칙으로 만든 가짜 불일치가 실제 모델이 내는 [[환각]]과 다르다는 비판이 이후 논문들에서 나왔다. 모델은 규칙 변형보다 미묘하게 틀린다.

## 실험 계획

[[한국어 요약의 환각 측정과 완화]]에서 [[exp-002 baseline 재현]] 다음으로 붙일 첫 지표로 정해져 [[exp-003 FactCC|exp-003]]으로 한국어 적용을 시도했다. 결과는 실패였다. 가짜 데이터 valid 정확도는 0.94였으나 [[exp-002 baseline 재현]]의 사람 평가 50개에서는 정확도 0.58에 그쳤다. 규칙으로 만든 불일치가 모델이 실제로 내는 [[환각]]과 다르다는 비판이 그대로 확인되었고, "FactCC 스타일은 한국어 뉴스 요약에서 안 된다"는 것 자체가 결과로 남았다. 이후 같은 사람 평가에서 [[SummaC]]-ZS 한국어 적용([[exp-004 SummaC|exp-004]])은 정확도 0.72로 FactCC보다 훨씬 나았다.
