# LLM-as-judge

> 세미나에서 나온 평가 아이디어. LLM-as-judge로 평가한 점수와 사람 평가 200개의 상관을 확인할 계획이며, API 비용이 걸림돌이다.

## 계획

사람 평가 200개와 LLM-as-judge 점수의 상관을 계산할 계획이다. 세미나에서 나온 아이디어인데, 상관이 잘 나오면 논문에 한 절이 더 생긴다. API 비용이 걸림돌이었으나 200개면 얼마 안 든다. 세미나에서 들은 바로 현업에서는 사람 평가와 LLM-as-judge를 섞어 쓰고, LLM 심판은 사람과 0.8 정도 상관한다. 한국어 신뢰도를 물었더니 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 했다.

## 검증 디코딩에는 못 넣는다
