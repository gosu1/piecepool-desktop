# 추상 요약

> 원문을 새로운 문장으로 요약하는 방식. 모델이 만든 요약은 유창하지만 원문에 없는 내용을 만들어내는 [[환각]] 문제가 있다.

## 환각 문제

추상 요약 모델은 유창하지만 원문에 없는 내용을 만드는 [[환각]]이 있다. [[On Faithfulness and Factuality in Abstractive Summarization]] 의 사람 평가에서 [[XSum]] 의 생성 요약 70% 이상에 [[환각]]이 있었다. 한국어 뉴스 요약에서는 [[exp-002 baseline 재현]] 에서 생성 요약 50개 중 22%에 [[환각]]이 있는 것을 처음 확인했다.
