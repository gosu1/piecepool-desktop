# exp-003 FactCC

> [[FactCC]]를 한국어 뉴스 요약에 적용한 실험. 가짜 데이터에서는 정확도 0.94였으나 사람 평가 50개에서는 0.58로 실패했다. 규칙 변형으로 만든 불일치와 모델이 실제로 내는 [[환각]]이 다르다는 것을 확인한 결과다.

## 진행

[[exp-002 baseline 재현]] 다음으로 [[FactCC]]를 첫 지표로 붙인 실험이다. 변형 규칙을 한국어로 옮겼다: 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사. 이렇게 가짜 데이터 2만 쌍을 만들어 klue/roberta-base를 이진 분류로 3 epoch 학습했다.

가짜 데이터 valid 정확도는 0.94로 좋아 보였으나, [[exp-002 baseline 재현]]의 사람 평가 50개에 적용하니 정확도 0.58로 거의 동전 던지기였다. 규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 식인데 규칙 변형은 너무 티가 났다.

한 시간 낙담했지만 "[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"도 결과라고 정리했다. [[교수님]]이 안 되는 걸 보이는 것도 결과라고 한 것과 같은 결론이다. 다음은 [[SummaC]](exp-004)로, 학습 없이 NLI만 쓰므로 이 문제가 없다. 이 실험은 [[한국어 요약의 환각 측정과 완화]]의 일부다.
