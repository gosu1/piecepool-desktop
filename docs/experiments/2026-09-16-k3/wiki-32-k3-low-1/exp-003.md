# exp-003

> [[FactCC]] 변형 규칙을 한국어로 만들어 klue/roberta-base 이진 분류기를 학습한 실험. 가짜 데이터에서는 정확도 0.94였지만 사람 평가 50개에서는 0.58로 거의 동전 던지기라 실패로 끝났다.

## 진행 상황

[[FactCC]] 변형 규칙을 한국어로 다시 짰다: 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사 바꾸기. 이 규칙으로 가짜 데이터 2만 쌍을 만들어 klue/roberta-base 이진 분류기를 3 epoch 학습했다.

결과는 실패다. 가짜 데이터 valid 정확도는 0.94로 좋아 보였지만, [[exp-002]]의 사람 평가 50개에 적용하니 정확도 0.58로 거의 동전 던지기였다. 규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 [[환각]]은 숫자 하나가 슬쩍 바뀌는 식인데 내 변형은 너무 티가 났다.

"[[FactCC]] 스타일은 한국어 뉴스 요약에서 안 된다"도 결과다. 한 시간 낙담했지만 이게 결과다. 다음은 [[SummaC]]로 넘어간다 ([[exp-004]]). 학습 없이 NLI만 쓰니까 이 문제가 없다.
