# exp-002

> [[exp-001]]의 토크나이저 문제를 고쳐 [[KoBART]] 요약 baseline 재현에 성공한 실험. 생성 요약 50개를 직접 읽어 [[환각]] 비율 22%를 확인했고, 이것이 첫 사람 평가 데이터가 되었다.

## 결과

[[exp-001]]의 토크나이저 문제를 고쳐 다시 돌렸다. [[ROUGE]]-1 0.50 / [[ROUGE]]-L 0.46으로 데모 수치(0.52 / 0.47)와 거의 같아 재현 성공으로 본다.

## 환각 확인

생성 요약 50개를 직접 읽어 확인했더니 원문에 없는 내용이 들어간 것이 11개(22%)였다. 대부분 숫자나 날짜가 바뀐 intrinsic이고, 아예 없는 사실 추가(extrinsic)는 2개였다. [[On Faithfulness and Factuality in Abstractive Summarization]]의 70%보다 훨씬 낮은데, XSum이 한 문장 요약이라 더 심하고 뉴스 여러 문장 요약은 덜한 듯하다. 그래도 22%면 문제다. 이 50개는 스프레드시트에 저장한 첫 사람 평가 데이터다.
