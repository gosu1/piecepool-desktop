# exp-001

> [[KoBART]] 요약 baseline 재현 실험. 토크나이저 차이 때문에 데모 수치보다 한참 낮게 나왔다.

## 설정

[[KoBART]] 요약 모델(gogamza/kobart-summarization)로 AIHub 뉴스 요약 valid 1000개를 돌렸다. max_len 512 / 128, beam 4.

## 결과

[[ROUGE]]-1 0.31 / ROUGE-L 0.29. 데모 페이지 수치는 0.52 / 0.47로 한참 낮았다.

## 원인

토크나이저가 원인이었다. 허깅페이스 토크나이저 대신 원래 [[KoBART]] 토크나이저(kobart_tokenizer)를 써야 한다. 특수 토큰이 다르게 들어가서 문장 앞이 잘린다. 원인 찾는 데 2시간 걸렸다. [[exp-002]]에서 고쳐 다시 돌려 데모 수치 재현에 성공했다.
