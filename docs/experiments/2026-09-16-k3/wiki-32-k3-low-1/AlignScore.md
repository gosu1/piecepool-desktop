# AlignScore

> Zha et al. 2023의 사실 일관성 평가 모델. 7가지 태스크 데이터를 전부 '문맥-주장 쌍이 정렬되나'로 통일해 하나의 모델로 학습한다. 470만 쌍으로 학습해 [[SummaC]] Benchmark에서 SOTA다.

## 방법

NLI, QA, 요약, 패러프레이즈 등 7가지 태스크 데이터를 전부 '문맥-주장 쌍이 정렬(alignment)되나'라는 하나의 형식으로 바꿔 하나의 모델을 학습한다. 학습 데이터는 470만 쌍이다. 아이디어는 '사실 일관성 = 정렬' 하나로 보는 것이고, 데이터를 많이 모을 수 있어서 이긴 듯하다. base(125M) 모델도 large 못지않다고 한다.

## 성능

[[SummaC]] Benchmark에서 SOTA이며, [[SummaC]]-Conv보다 좋다.

## 한국어 적용 검토

한국어 버전을 만들려면 7가지 태스크의 한국어 데이터가 있어야 한다. [[KLUE-NLI]]와 KLUE STS가 있고, KorQuAD QA가 있고, 요약은 AIHub에 있다 — 실험 데이터로 [[AIHub 문서요약]]의 뉴스 부분을 골랐다. 패러프레이즈는 빠진 4종으로 [[exp-006]]에서 실제로 학습했다: [[KLUE-NLI]], KLUE-STS(임계로 이진화), KorQuAD(질문+답을 주장 문장으로 변환), [[AIHub 문서요약]](참조 요약 = 정렬), 약 40만 쌍으로 원논문의 1/10이다. klue/roberta-base를 A6000 하나로 6시간 학습해 사람 평가 200개에서 정확도 0.74, 스피어만 상관 0.41로 [[SummaC]]-ZS(0.70, 0.36)보다 조금 나았다. 숫자가 바뀐 경우는 여전히 못 잡는다.
