# LLM-as-judge

> LLM을 심사자로 써서 사실 일관성을 평가하는 방식. 현업에서는 사람 평가와 섞어 쓰며, LLM 심판은 사람과 0.8 정도 상관한다고 한다. 한국어에서도 GPT-4급이면 쓸 만하다.

## 계획

세미나(김OO 박사)에서 현업 이야기를 들었다. 현업에서는 평가를 사람 + LLM-as-judge를 섞어서 하고, LLM 심판은 사람과 0.8 정도 상관한다고 한다. 한국어에서 LLM 심판 신뢰도를 질문했더니 영어보다 조금 낮지만 GPT-4급이면 쓸 만하다고 했다.

사람 평가 200개에 LLM-as-judge를 붙여 상관을 재면 논문에 한 절이 더 생긴다. API 비용이 걱정이었는데 200개면 얼마 안 든다.

[[exp-007]] [[검증 디코딩]]의 NLI 자리에 LLM 심판을 넣는 것도 생각해 봤지만 느려서 안 될 듯하다. 평가에만 쓴다.
