# SQL

> 관계형 데이터베이스를 다루는 언어. SELECT, FROM, WHERE 기본에서 JOIN, GROUP BY, CTE, [[인덱스]], [[트랜잭션]]까지 배웠고 [[도서관 좌석 알림 앱|캡스톤]]에 썼다. [[윈도우 함수]]는 아직 모른다.

## 배운 것

SELECT, FROM, WHERE 기본에서 시작해 JOIN(INNER / LEFT), GROUP BY + 집계, 서브쿼리와 CTE(WITH), [[인덱스]] 있는 열로 WHERE 걸고 EXPLAIN 으로 확인하는 것, [[트랜잭션]](BEGIN/COMMIT)까지 배웠다. 서브쿼리보다 CTE 가 읽기 좋다 — [[클린 코드]] 정신과 통한다. [[도서관 좌석 알림 앱|캡스톤]]에서 좌석-엔티티 LEFT JOIN, 요일별 점유율(GROUP BY), 알림 등록 [[트랜잭션]]으로 직접 썼다.

## 모르는 것

[[윈도우 함수]] 를 모른다. ROW_NUMBER, LAG 같은 것인데 수업에서 안 배웠고 [[모두테크 데이터 인턴|인턴]]에서 쓸 것 같아 유튜브로 따로 볼 예정이다. 인턴 준비로 PostgreSQL을 로컬에 설치해 [[도서관 좌석 알림 앱|캡스톤]] DB로 연습하기로 했다.
