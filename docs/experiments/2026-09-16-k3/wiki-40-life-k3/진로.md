# 진로

> 데이터 쪽으로 가고 싶지만 데이터 안에서도 갈래가 많아 좁히는 중이다. 이해하는 일을 좋아하고 만드는 일은 덜 좋아해 리서치·대학원을 떠올리지만 대학원은 두렵다.

## 좋아한 것과 싫었던 것

데이터 쪽으로 가고 싶은 건 맞는데 데이터 분석가, 데이터 엔지니어, ML 엔지니어, 리서치가 다 달라서 갈래를 못 정했다. 좋아한 것은 [[DETR]] 을 읽고 이해했을 때, [[도서관 좌석 알림 앱]] 캡스톤 DB 스키마를 짰을 때, 통계 [[t검정]] 을 손으로 풀 때다. 싫었던 것은 [[운영체제]] 과제 [[파이프]] 디버깅 3시간, [[DP]] 점화식, 자소서다. 이걸 볼 때 이해하는 것을 좋아하고 만드는 것은 별로인가 싶어 리서치나 대학원을 떠올렸다.

## 대학원에 대한 두려움

대학원은 무섭다. [[김교수님]] 랩 학생들을 볼 때 다들 지쳐 보인다.
