# 모두테크 데이터 인턴

> 모두테크의 데이터 인턴. 최종 합격해 12월 1일부터 3개월간 데이터 팀에서 주 3일 일한다. 회사는 교육 데이터와 학습 로그 분석을 한다.

## 자소서

문항은 지원 동기, 프로젝트 경험, 성장 세 개이고 각 500자다. 지원 동기 초안은 "데이터를 다루는 일에 관심이 있다"로 시작했는데 너무 뻔해서 다시 쓰기로 했다. 프로젝트 경험에는 [[도서관 좌석 알림 앱]] 이 아직 시작 단계라 쓸 게 없고, [[CIFAR-10 분류 과제]] 는 다들 하는 거라 차별점이 없다고 느낀다. 성장 문항에는 [[DETR]] 발표 때 디코더를 모른다는 걸 인정하고 원논문으로 돌아가 이해한 일을 쓸 만한지 고민 중이다. 500자를 넘기는 게 아니라 채우는 게 어렵다. 자소서 쓰기 자체는 내가 싫어하는 일 가욘데 하나다. [[김교수님]]께 지원한다고 했더니 거기 아는 사람이 있다고 하셨고, 데이터 팀이 작아서 인턴한테 실제 일을 시킨다고 하셨다. 좋은 건지 나쁜 건지 모르겠다. 인턴은 일단 합보는 것이고, 실제 회사 데이터 팀이 뭘 하는지 볼 때 [[진로]] 가 갈리겠다고 생각한다. [[추석]]에 친척들에게 지원한다고 했더니 아묻도 모르셨고, 스타트업이라고 하니 분위기가 미묘해졌다. 2차 수정을 [[지훈]]이 봐줬는데 "왜 이 회사인지가 없다"고 지적했고, 맞는 말이다. 솔직히 왜 이 회사인지 나도 모른다 — 데이터 인턴을 뽑는 곳 중에 서류가 안 복잡해서 지원한 것이다.

[[지훈]]이 지적에 따라 모두테크 홈페이지를 다시 봤다. 회사가 학습 로그로 학생별 취약 단원을 찾는다는 것을 알았고, 이것이 [[도서관 좌석 알림 앱|캡스톤]]에서 좌석 로그로 패턴을 찾으려는 것과 구조가 같다고 느꼈다 — 로그를 모으고 패턴을 찾는다. 이 연결로 지원 동기 2차를 썼다: 캡스톤에서 도서관 좌석 로그를 모으며 "언제 자리가 나는지" 패턴을 찾으려 했고, 모두테크가 학습 로그에서 취약 단원을 찾는 것과 같은 구조라고 생각해 로그를 모으고 패턴을 찾는 일을 실제 데이터로 합보고 싶다는 내용이다. 다만 캡스톤은 [[지훈]]이 서버를 안 올려서 아직 로그도 모으지 못했으므로 과장이 아닌지 걱정된다. 계획은 있으니 쓰기로 했다. 성장 문항은 [[DETR]] 얘기 그대로인데 [[지훈]]이가 좋다고 했다. 프로젝트 경험 문항은 캡스톤 진행이 없어서 못 쓰므로 딥러닝 과제([[CIFAR-10 분류 과제]])로 대체하되, 정확도 대신 "왜 85%에서 안 오르는지 찾다가 데이터 불균형을 발견"한 이야기로 쓴다. 이것도 사실이다. [[추석]]에 절반, 그다음 날 절반을 썼다.

자소서를 냈다. 마감 2분 전인 밤 11시 58분에. [[지훈]] 말대로 "왜 이 회사인지"를 넣긴 했는데 반은 지어낸 거다 — 좌석 알림 앱을 만들면서 데이터 [[파이프]]라인에 관심이 생겼다고 썼는데, 관심이 생긴 건 맞지만 그게 모두테크여야 하는 이유는 아니다.

## 서류 합격

서류에 붙었다. 메일은 [[부산 여행]] 중에 봤고, [[민지]]가 자기 일처럼 좋아했다. 내일 코딩테스트다.

## 코딩테스트

서류 합격 후 코딩테스트를 준비했다. 4문제 90분이고 언어는 자유라 파이썬으로 봤다. 인터넷 후기 기준 예상 유형은 구현, 그래프, [[DP]], 문자열이었다. [[DP]]가 약해서 스터디 계단 문제를 다시 풀고 1149, 9095를 풀었지만 12865(배낭)는 못 풀어 나오면 버리기로 했다. 시간 배분은 문제당 20분, 안 되면 넘기기로 했고, [[지훈]]이 못 풀겠으면 브루트포스로 부분 점수라도 노리라고 조언했다.

10/8에 봤다. 4문제 중 2문제를 풀었고 하나는 시간 초과, 마지막은 못 봤다. 막힌 문제가 [[DP]]였다 — 스터디에서 못 푼 게 그대로 나왔다. 결과가 어떻든 [[DP]]는 진짜 잡아야겠다고 느꼈다.

## 면접

10/15에 30분, 면접관 세 명으로 봤다. [[도서관 좌석 알림 앱|캡스톤]] 얘기를 많이 했다 — 좌석 로그를 모아 요일 패턴을 찾겠다는 것. "지금 데이터 얼마나 있냐"는 질문에 하루치라고 솔직히 말했고 면접관들이 웃었다. 자소서에 쓴 [[DETR]] 내용("디코더 몰라서 원논문 봤다")도 물어봤는데 대답을 잘한 것 같다. 마지막에 "데이터 분석이랑 엔지니어링 중 뭐가 더 좋냐"고 물어 분석이라고 답했다 — [[진로]] 고민 노트에 썼던 내용 그대로다. 모두테크는 Postgre[[SQL]]을 쓴다고 면접 때 들었다 — 캡스톤과 같아서 다행이다. 결과는 일주일 뒤에 나온다.

## 최종 합격

붙었다. 12월 1일부터 3개월간 데이터 팀에서 주 3일 일한다. 합격 메일에는 "[[도서관 좌석 알림 앱|캡스톤]] 로그 얘기가 인상적이었다"고 적혀 있었다 — 면접에서 데이터가 하루치밖에 없다고 솔직히 말한 게 오히려 좋았던 것 같다. [[김교수님]]께 말씀드렸더니 "거기 데이터 팀 작아서 실제 일 시킨다"는 말씀을 다시 하시며 배울 거라고 하셨다. [[민지]], [[지훈]], [[수아]]에게 카톡으로 알렸고 [[지훈]]이가 제일 먼저 축하했는데, [[지훈]]이는 코테에 떨어졌었으니 미안한 마음이 들었다. 부모님께 전화했더니 엄마가 우셨고 아빠는 "그래" 한마디였다. 이제 [[노트북]]을 살 수 있다 — 맥북 에어로, 12월 첫 월급에.

## 준비

12월 1일 시작 전 준비 목록을 세웠다. [[윈도우 함수]]를 유튜브로 공부하고, Postgre[[SQL]]을 로컬에 설치해 [[도서관 좌석 알림 앱|캡스톤]] DB로 연습한다. 판다스를 복습하되 [[클린 코드]]에서 지적한 df, df2 같은 이름부터 고치기로 했다. 캡스톤 로그 분석(요일별 점유율)을 포트폴리오로 정리할 계획이다. 주 3일 근묘이므로 남는 이틀은 캡스톤 최종 발표(12/5) 준비에 쓴다.
