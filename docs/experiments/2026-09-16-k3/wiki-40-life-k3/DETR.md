# DETR

> 2020년 Facebook AI가 발표한 객체 검출 모델. 객체 검출을 집합 예측 문제로 보고, 바이파타이트 매칭 손실과 트랜스포머 인코더-디코더로 NMS·앵커 같은 수작업 구성 요소 없이 한 번에 예측을 출력한다. COCO에서 Faster R-[[CNN]]과 비슷한 성능을 낸다.

## 핵심 아이디어

객체 검출을 직접적인 집합 예측(direct set prediction) 문제로 본다. 이를 통해 NMS(non-maximum suppression)나 앵커 생성처럼 사전 지식을 인코딩하는 수작업 구성 요소를 제거한다. 두 가지 핵심 요소는 (1) 바이파타이트 매칭으로 유일한 예측을 강제하는 집합 기반 전역 손실, (2) [[트랜스포머]] 인코더-디코더 아키텍처다. 고정된 소수의 학습된 오브젝트 쿼리가 주어지면, 객체들 간의 관계와 이미지 전체 맥락을 이용해 최종 예측 집합을 병렬로 한 번에 출력한다.

## 아키텍처

세 가지 주요 구성 요소로 이루어진다: [[CNN]] 백본, [[트랜스포머]] 인코더-디코더, 최종 예측을 만드는 FFN. [[CNN]] 백본([[ResNet]]-50/101)이 낮은 해상도의 활성화 맵(채널 2048, 1/32 해상도)을 만들고, 1x1 합성곱으로 채널을 줄인 뒤 공간 차원을 펼쳐 인코더에 넣는다. 디코더는 원래 [[트랜스포머]] 디코더에서 masked 어텐션만 뺀 것이고 cross attention은 그대로다 — 출력이 순서 없는 집합이라 뒤를 가릴 이유가 없어 masked를 안 쓴다. 디코더는 N개의 학습된 오브젝트 쿼리를 입력으로 받아 각 층에서 N개의 객체를 병렬로 디코딩한다. 오브젝트 쿼리는 원래 디코더에서 이전 출력 단어가 들어가는 입력 자리에 대신 넣는 학습된 벡터로, DETR은 고정된 100개를 넣는다. 각 출력 임베딩은 공유 FFN(3층 [[퍼셉트론]])을 거쳐 클래스와 박스로 변환되며, 객체가 없는 슬롯은 특수 클래스 ∅로 예측된다. 기본 모델은 인코더 6층, 디코더 6층, 너비 256, 8개 어텐션 헤드, N=100 쿼리를 사용한다.

## 손실 함수

먼저 헝가리안 알고리즘으로 예측과 정답 사이의 최적 바이파타이트 매칭을 찾는다. 매칭 비용은 클래스 예측 확률과 박스 유사도를 함께 고려한다. 이후 매칭된 쌍에 대해 클래스 음의 로그 우도와 박스 손실의 선형 결합(헝가리안 손실)을 계산한다. 박스 손실은 l1 손실과 스케일 불변인 GIoU 손실의 선형 결합이다(가중치 λL1=5, λiou=2). ∅ 클래스의 로그 확률은 클래스 불균형 때문에 10배 낮춘다. 매칭 비용에는 log-probability 대신 probability를 쓰는데, 이렇게 하면 클래스 항이 박스 손실과 같은 스케일이 되어 실험적으로 성능이 좋았다. 디코더 층마다 보조 손실(auxiliary loss)을 단다.

## 실험 결과

COCO validation에서 Faster R-[[CNN]]과 비슷한 성능(42 AP)을 달성했다. 큰 객체에서는 APL이 +7.8로 크게 좋지만 작은 객체에서는 APS가 -5.5로 뒤처진다. 인코더 층이 없으면 AP가 3.9 하락(큰 객체는 6.0 하락)하며, 디코더는 층이 깊어질수록 AP가 개선된다(첫 층 대비 마지막 층에서 +8.2). NMS는 설계상 필요 없으며, 오히려 마지막 층에서는 진양성을 제거해 AP를 낮춘다. FFN을 제거하면 2.3 AP 하락, 공간 위치 인코딩을 완전히 빼면 7.8 AP 하락. GIoU 손실 단독으로도 기본 모델 대비 0.7 AP 차이밖에 나지 않지만, l1 단독은 결과가 나쁘다. 파놉틱 세그멘테이션으로 확장 시 마스크 헤드를 붙이는 것만으로 기존 베이스라인들을 능가한다(특히 stuff 클래스에서 우세).

## 학습 설정

AdamW를 사용하며 트랜스포머 학습률 1e-4, 백본 학습률 1e-5, weight decay 1e-4. 백본은 ImageNet 사전학습 [[ResNet]]에 배치 [[정규화]]를 고정하고, 백본 학습률을 나머지보다 한 자릿수 작게 하는 것이 초기 안정화에 중요하다. 300 에폭 학습에 V100 16장으로 3일 소요(배치 64). 500 에폭의 긴 스케줄은 300 에폭보다 1.5 AP를 더 얻는다. 랜덤 크롭 증강은 약 1 AP 개선에 기여한다. 추론 시 ∅로 예측된 슬롯을 두 번째로 높은 클래스로 덮어쓰면 AP가 2점 오른다.

## 한계

작은 객체에서 성능이 낮고, 긴 학습 스케줄이 필요하다. 쿼리 슬롯 수(100)보다 많은 객체는 예측할 수 없으며, 인스턴스 수가 100에 가까워지면 포화되어 놓치는 객체가 늘어난다(100개가 보일 때 평균 30개만 검출). 다만 50개까지는 거의 완벽하게 검출해 클래스별 인스턴스 수 분포에 과적합하지는 않는다.
