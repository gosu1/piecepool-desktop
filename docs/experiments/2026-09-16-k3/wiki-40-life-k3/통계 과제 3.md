# 통계 과제 3

> 통계학 과제 3. 데이터를 골라 회귀를 돌리고 해석하는 과제로, [[가계부]] 데이터를 쓰기로 했다.

## 데이터 계획

[[가계부]] 데이터를 쓰기로 했는데 처음에는 9월 한 달이라 30행뿐이었다. 10월이 끝나 이제 데이터가 두 달치가 됐다. [[수면]]은 10월부터 기록 중이라 11월에 두 달치로 돌린다.

## 변수 후보

변수 후보는 [[커피]] 지출, 취침 시각, 운용 여부이고, 결과 변수는 다음 날 집중도(1~5 자기 평가)다. 자기 평가라 노이즈가 클 것 같다.

## 교수님 조언

교수님 말로는 30행에 변수 3개면 위험하다 — 과적합이다. 변수 하나로 시작하라고 하셨다.

## 첫 회귀 결과

11월에 두 달치 [[가계부]] + [[수면]] 기록으로 [[단순 선형 회귀]] 를 처음 돌렸다. 교수님 말씀대로 변수 하나(취침 시각 → 다음 날 집중도)로 시작했다. 기울기가 음수로 나왔고(늦게 자면 집중이 떨어짐), [[p값]] 은 0.03 이었다. 다만 집중도가 자기 평가라 이 결과를 믿어도 되는지 의문이다. 두 번째 변수로 [[커피]] 지출을 넣으니 [[커피]] 계수가 유의하지 않았다 — 취침 시각과 상관이 높아서(늦게 자는 날 [[커피]]를 많이 마심) [[다중공선성]] 이었다. 6주차에 배운 내용 그대로다. 내 데이터로 하니까 재밌다.
