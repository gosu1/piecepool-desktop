# 설문 문항 (초안)

- 목적: 인터뷰에서 발견한 패턴을 **수치로 확정**한다
- 대상: 논문·강의자료를 주기적으로 읽는 학부 연구생·대학원생·연구자
- 목표 응답: **50명 이상** (30명 미만이면 비율을 퍼센트로 쓰지 말고 인원수로 쓴다)
- 소요: 응답자 기준 4~5분
- 시점: **인터뷰 이후.** 10~11월 멘토링 기간에 수집해 본선 발표에 쓴다

> ⚠️ **인터뷰보다 먼저 돌리지 말 것.**
> 설문 문항에는 우리 가설이 박혀 있어서, 응답자가 그 틀 안에서만 답한다.
> 인터뷰에서 **사람들이 실제로 쓰는 표현**을 얻은 뒤 그 표현으로 문항을 고쳐야 한다.
> 아래는 그 전의 초안이다.

---

## 설계 원칙

| ❌ 넣지 않는다                       | ✅ 대신 넣는다                               |
| ------------------------------------ | -------------------------------------------- |
| "이런 서비스가 있으면 쓰시겠습니까?" | "최근 한 달간 몇 번 그러셨습니까?"           |
| "불편하십니까?" (5점 척도)           | "그때 몇 분 걸렸습니까?"                     |
| "얼마면 지불하시겠습니까?"           | **"현재 어떤 도구에 얼마를 쓰고 계십니까?"** |

의향을 물으면 전부 허수가 된다. **이미 일어난 행동만 묻는다.**

---

## 문항

### A. 스크리닝

**A1.** 최근 3개월간 논문, 강의자료, 기술문서 중 하나라도 정기적으로 읽으셨습니까?

- 예 / 아니오 → _아니오면 설문 종료_

**A2.** 현재 신분을 선택해 주세요.

- 학부생 / 학부 연구생 / 석사과정 / 박사과정 / 박사후연구원 / 기업 연구원 / 기타

**A3.** 전공 계열

- 공학 / 자연과학 / 의약학 / 인문사회 / 예체능 / 기타

---

### B. 자료 소비량

**B1.** 주당 읽는 분량이 대략 어느 정도입니까? (복수 응답)

- 강의자료: 50p 미만 / 50~~150p / 150~~300p / 300p 이상 / 해당 없음
- 논문: 1편 미만 / 1~~2편 / 3~~5편 / 5편 이상 / 해당 없음

**B2.** 읽으면서 노트를 남기십니까?

- 항상 남긴다 / 중요한 것만 / 거의 안 남긴다 / 전혀 안 남긴다

**B3.** (B2 에서 남긴다고 답한 경우) 어떤 형태입니까? (복수 응답)

- 원문에 하이라이트·주석 / 별도 요약 노트 / 내 말로 다시 쓴 정리 / 손글씨 / 기타

---

### C. 복원 경험 ⭐ 핵심 구간

**C1.** 최근 한 달간, **예전에 읽었던 자료를 다시 찾아야 했던 적**이 몇 번 있었습니까?

- 0번 / 1~~2번 / 3~~5번 / 6~10번 / 10번 이상

**C2.** 가장 최근에 그러셨던 때를 떠올려 주세요. **찾는 데 얼마나 걸렸습니까?**

- 5분 미만 / 5~~15분 / 15~~30분 / 30분~1시간 / 1시간 이상 / **결국 찾지 못했다**

> 마지막 선택지의 비율이 1-1 에서 가장 강한 한 줄이 된다.

**C3.** 그때 **직접 작성한 노트를 먼저 보셨습니까?**

- 보았다 / 노트가 없었다 / 노트가 있는지 몰랐다 / 노트를 찾지 못했다

**C4. ⭐ 문제 정의를 직접 검증하는 문항**
(C3 에서 "보았다"를 선택한 경우) **노트를 보고 해결되었습니까?**

- 노트만으로 해결되었다
- **노트에 내용은 있었으나 이해가 잘 안 되어 원본을 다시 봤다**
- **노트가 너무 짧거나 맥락이 없어 원본을 다시 봤다**
- **노트의 내용이 어느 자료에서 나온 것인지 알 수 없어 원본을 찾아야 했다**
- 기타 (직접 입력)

> 2~4번 선택지의 합이 **우리 문제 정의의 지지율**이다.

**C5.** 결국 무엇을 더 보셨습니까? (복수 응답)

- 원본 자료 / 블로그·해설글 / 유튜브 / ChatGPT 등 생성형 AI / 동료에게 질문 / 기타

---

### D. 정리 비용

**D1.** 노트를 정리하는 데(폴더 분류, 태그 달기, 링크 연결 등) **주당 몇 시간**을 쓰십니까?

- 거의 안 쓴다 / 1시간 미만 / 1~~3시간 / 3~~5시간 / 5시간 이상

**D2.** 정리 체계를 만들어 두었다가 **유지하지 못하고 흐지부지된 경험**이 있습니까?

- 있다 / 없다 / 애초에 체계를 만들지 않았다

---

### E. 도구 사용 이력 (지불 의사의 실제 신호)

**E1.** 현재 사용 중인 도구를 모두 선택해 주세요.

- Obsidian / Notion / OneNote / Zotero / Mendeley / Google Drive·Docs / 로컬 폴더만 / 종이 / 기타 / 사용 안 함

**E2.** 위 도구 중 **유료로 결제해 본 것**이 있습니까?

- 있다 (무엇인지 입력) / 없다

**E3.** 지식관리·노트 도구에 **현재 월 얼마를 지출**하고 계십니까?

- 0원 / 1만원 미만 / 1~~3만원 / 3~~5만원 / 5만원 이상

**E4.** 써 보다가 **그만둔 도구**가 있습니까? 있다면 무엇이고 왜 그만두셨습니까? (주관식)

---

### F. AI 사용 실태

**F1.** 본인의 노트나 자료를 AI 서비스(ChatGPT, Claude 등)에 **직접 넣어서** 활용해 보신 적이 있습니까?

- 정기적으로 한다 / 몇 번 해봤다 / 해보려 했으나 실패했다 / **그런 게 가능한 줄 몰랐다** / 알지만 안 한다

> 4번 선택지의 비율이 **"경로가 개발자 전용이다"** 라는 우리 주장의 근거가 된다.

**F2.** (F1 에서 "알지만 안 한다"를 선택한 경우) 이유는 무엇입니까? (복수 응답)

- 설정이 복잡해서 / 보안이 걱정되어 / 비용 때문에 / 필요를 못 느껴서 / 기타

**F3.** **미발표 연구 자료나 민감한 내용**을 클라우드 AI 서비스에 올리는 것에 대해 어떻게 생각하십니까?

- 전혀 문제없다 / 별로 신경 안 쓴다 / 조금 꺼려진다 / 매우 꺼려진다 / **규정상 금지되어 있다**

> 4~5번의 합이 **로컬 구조의 시장 근거**가 된다.

---

### G. 마무리

**G1.** 위 내용과 관련해 하고 싶은 말씀이 있으면 자유롭게 적어 주세요. (주관식)

**G2.** 시제품이 나왔을 때 사용해 보실 의향이 있으시면 이메일을 남겨 주세요. (선택)

> G2 는 의향 조사가 아니라 **연락처 확보**가 목적이다.
> 응답률 자체를 "관심도"로 사용할 수는 있으나, 그것을 지불 의사로 해석하지 않는다.

## 분석 계획 — 돌리기 전에 정해 둔다

| 지표                 | 계산                                | 쓰이는 곳           |
| -------------------- | ----------------------------------- | ------------------- |
| **복원 실패율**      | C2 에서 "결국 찾지 못했다" 비율     | 1-1 나 절           |
| **평균 복원 시간**   | C2 의 구간 중앙값 가중평균          | 1-1 나 절 · 1-2     |
| **문제 정의 지지율** | C4 의 2~4번 합 / C3 "보았다" 응답자 | **1-1 전체의 근거** |
| **정리 비용**        | D1 의 구간 중앙값                   | 1-1 라 절 ①         |
| **이탈 경험률**      | D2 "있다" 비율                      | 1-1 라 절 ①         |
| **지불 경험률**      | E2 "있다" 비율                      | 1-2 · 3장           |
| **인지 격차**        | F1 "가능한 줄 몰랐다" 비율          | 1-1 라 절 ④         |
| **로컬 필요성**      | F3 의 4~5번 합                      | 3장                 |

### 판정 기준

| 문제 정의 지지율 (C4) | 판정                                                            |
| --------------------- | --------------------------------------------------------------- |
| 70% 이상              | 1-1 확정. 수치를 그대로 인용한다                                |
| 40~70%                | 유효하나 타겟을 좁혀 재분석한다 (전공·과정별 교차분석)          |
| 40% 미만              | **1-1 을 다시 쓴다.** C4 기타 응답과 G1 에서 실제 고통을 찾는다 |

## 배포 계획

| 경로                       | 예상 응답 |
| -------------------------- | --------- |
| ERICA 학과·연구실 단톡방   | 20~30     |
| 인터뷰 대상자의 소개 (Q14) | 5~10      |
| 대학원생 커뮤니티          | 10~20     |

**30명을 넘기지 못하면 퍼센트를 쓰지 않는다.** "응답자 22명 중 15명"처럼 인원수로 쓴다. 표본이 작은데 퍼센트를 쓰면 심사에서 신뢰를 잃는다.
