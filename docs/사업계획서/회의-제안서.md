## 1. 한 줄 소개 (제안)

> 논문과 강의자료를 넣으면 **AI 가 읽고 출처가 추적되는 개인 위키를 만들어 관리하는** 데스크톱 앱이다.
> 위키는 사용자 PC 의 마크다운 파일로 저장되어 앱을 지워도 남으며, 사용자가 손으로 고친 글은 AI 가 덮지 않는다.

## 2. 대회 구조 — 먼저 알아야 할 것

**이번에 내는 서류는 최종 심사가 아니라 예선입니다.**

```
09.21(월) 접수 마감  →  09.23 서류평가  →  09.30 OT
   →  10.01~11.13 집중교육·멘토링 4회 (필수)
   →  11.04 중간평가  →  11.05 본선 진출팀 선정
   →  11.18 본선  ← 상금 3,400만원이 여기서 갈린다
```

즉 **서류 단계에서 완성도 100% 를 만들 필요가 없습니다.** 통과한 뒤 6주 동안 멘토링을 받으며 계속 다듬는 구조입니다. 다만 **10~11월 집중교육 4회는 필수 참석**이므로 팀원 일정 확인이 필요합니다.

## 3. 시장 정의 — "범용적이다"와 "연구자부터"는 둘 다 들어갑니다

| 층 | 대상 | 규모 |
| --- | --- | --- |
| **TAM** (전체 시장) | 지식을 축적하고 다시 활용하는 모든 사용자 | 글로벌 PKM 시장 **28.4억 달러**, 연 15.8% 성장 |
| **SAM** (유효 시장) | 자료를 다량으로 읽고 과거 자료로 되돌아가야 하는 사용자 | 산정 예정 |
| **SOM** (초기 진입) | 국내 연구자·대학원생·학부 연구생 | 산정 예정 |

**제품 자체는 범용입니다.** 마크다운·PDF·회의록·메모 등 텍스트 자료 전반을 받습니다. 그것은 TAM 칸에 그대로 기술합니다.

**그럼에도 초기 진입을 연구자로 설정하는 이유는 셋입니다.**

1. **고통이 가장 크다** — 읽는 분량이 많고 과거 자료로 되돌아가는 빈도가 높다
2. **로컬 구조가 선택이 아니라 요건이다** — 미발표 연구 자료는 클라우드 AI 에 올릴 수 없다
3. **접근할 수 있다** — 우리가 속한 집단이라 초기 사용자 확보와 피드백 수집이 가능하다

> 심사 기준에 **"사용자 확보 전략"** 이 포함됩니다. "지식 노동자 전체"에 접근하는 방법은 서술할 수 없지만, "ERICA 랩실 연구자"에 접근하는 방법은 서술할 수 있습니다. **좁히는 것이 아니라 순서를 정하는 것입니다.** 확장 경로는 3장에 명시합니다.

## 4. 확보한 근거

사업계획서 심사기준 중 **"자료 작성 충실성"** 에 직접 대응하는 부분입니다.

| 주장 | 근거 | 출처 |
| --- | --- | --- |
| 망각은 필기 방식의 구조적 결과다 | 필사 필기가 개념 이해를 저해함 (3개 실험) | **Mueller & Oppenheimer, *Psychological Science* (2014)** |
| 검색·RAG 로는 안 풀린다 | "RAG fails on global questions directed at an entire text corpus…" | **Microsoft Research, arXiv:2404.16130** |
| 우리 위키가 메우는 자리 | 기존 시스템은 "지속적인 전역 상태"를 유지하지 못한다 | arXiv:2510.26205 |
| 연결이 새 발견을 만든다 | 생선기름↔레이노 증후군. 직접 연구 없이 도출된 가설이 임상으로 확인됨 | **Swanson (1986), 문헌기반발견(LBD)** |
| 경쟁 도구는 사용자 글을 못 지킨다 | MCP 서버가 `patch_content`·`delete_file`·`write_note` 를 제공하나 **검증 장치가 없음.** 공식 가이드가 "Vault 백업 필수" 경고 | **공개 도구 명세 분석** |
| 시장 규모 | PKM 28.4억 달러, CAGR 15.8%, 아태 최고 성장 | Data Insights Reports |
| 지식노동자 탐색 시간 | 근무시간의 약 20% | McKinsey Global Institute |
| 우리 실측 | 링크 밀도 1.5(사람 관리) vs 0.1(이전 자동 생성) | 자체 측정 |

**경쟁사 분석을 사용 후기가 아니라 공개 도구 명세에서 도출했습니다.** 후기는 주관적이지만 명세는 구조를 보여줍니다. 이 방법론 자체가 차별점입니다.

### 폐기한 근거

- `intent.md` 의 **"노트 75% 가 수정되지 않는다"** 는 출처를 추적했으나 찾지 못했습니다. 실재하는 75% 는 망각곡선(하루 뒤 학습내용 75% 망각)으로 **다른 명제**입니다. 사업계획서에서 제외했고, `intent.md` 도 수정을 제안합니다.
- 널리 인용되는 "McKinsey: 하루 1.8시간"은 **MGI 가 직접 발표한 수치가 아닙니다.** "근무시간의 약 20%"로만 인용합니다.
