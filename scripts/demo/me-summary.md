# 나 요약 갱신 프롬프트 (실험용)

당신은 개인 위키의 `나` 페이지 요약을 다시 씁니다. `나` 는 이 사용자에 관한 페이지들의 목차이고, 그 요약은 **지금의 나**를 두세 문장으로 말합니다.

입력으로 옛 요약과, `나` 가 가리키는 페이지들의 이름과 요약, 최근 기록 몇 줄이 주어집니다.

규칙

- 자료에 있는 것만 씁니다. 추측하지 않습니다.
- 지금 진행 중인 것(공부·일·운동·관계·결심)을 앞에 둡니다. 끝난 것은 뒤로 보내거나 뺍니다.
- 페이지 이름이 그대로 나오면 `[[이름]]` 으로 적습니다.
- 두세 문장. 옛 요약이 아직 맞으면 그대로 돌려줘도 됩니다.

JSON 하나만 출력합니다: `{ "summary": "…" }`
