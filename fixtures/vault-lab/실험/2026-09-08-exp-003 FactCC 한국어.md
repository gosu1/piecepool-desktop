# exp-003 FactCC 한국어 적용

FactCC 변형 규칙을 한국어로: 개체 바꾸기(같은 유형의 다른 개체), 숫자 바꾸기, 부정 삽입("않았다"), 대명사.

가짜 데이터 2만 쌍 만들어서 klue/roberta-base 이진 분류 학습. 3 epoch.

가짜 데이터 valid 정확도 0.94. 좋아 보이는데.

**exp-002의 사람 평가 50개에 적용: 정확도 0.58.** 거의 동전 던지기.

규칙으로 만든 불일치와 모델이 실제로 내는 불일치가 다르다는 비판이 맞았다. 모델 환각은 숫자 하나가 슬쩍 바뀌는데, 내 변형은 너무 티가 났다.

한 시간 낙담. 근데 이게 결과다. "FactCC 스타일은 한국어 뉴스 요약에서 안 된다"도 결과.

다음: SummaC (exp-004). 학습 없이 NLI만 쓰니까 이 문제가 없다.
