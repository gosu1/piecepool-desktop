# exp-002 baseline 재현 (토크나이저 수정)

exp-001의 토크나이저 문제 고침.

결과: ROUGE-1 0.50 / ROUGE-L 0.46. 데모(0.52/0.47)와 거의 같음. 재현 성공으로 봄.

환각 확인: 생성 요약 50개를 직접 읽음. 원문에 없는 내용이 들어간 것 **11개 (22%)**. 대부분 숫자나 날짜가 바뀜 (intrinsic). 아예 없는 사실 추가는 2개.

Maynez 논문의 70%보다 훨씬 낮은데, XSum이 한 문장 요약이라 더 심한 거고 뉴스 여러 문장 요약은 덜한 듯. 그래도 22%면 문제.

이 50개가 내 첫 사람 평가 데이터. 스프레드시트에 저장.
