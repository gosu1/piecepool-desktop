인턴 전 SQL 복습. DB 수업 + 캡스톤에서 쓴 것.

- JOIN: INNER / LEFT. 캡스톤에서 좌석-열람실 LEFT JOIN
- GROUP BY + 집계. 요일별 점유율이 이거
- 서브쿼리보다 CTE (WITH) 가 읽기 좋다고 (클린 코드 정신)
- 인덱스 있는 열로 WHERE. EXPLAIN 으로 확인
- 트랜잭션: 알림 등록할 때 BEGIN/COMMIT. 5주차

모르는 것: 윈도우 함수. ROW_NUMBER, LAG. 인턴에서 쓸 것 같은데 수업에서 안 함. 유튜브로.

모두테크는 PostgreSQL 쓴다고 면접 때 들음. 캡스톤이랑 같다. 다행.
