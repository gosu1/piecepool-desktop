랩미팅 발표 준비로 DETR 읽기 시작. End-to-End Object Detection with Transformers.

핵심 주장

- 기존 객체 검출은 앵커박스, NMS 같은 손으로 만든 부품이 많다
- DETR 은 그걸 다 없애고 집합 예측 문제로 바꾼다
- 트랜스포머 인코더-디코더를 그대로 쓴다

구조

- CNN 백본으로 특징 뽑고 (ResNet 쓴다고 나옴)
- 그 특징을 펴서 트랜스포머 인코더에 넣고
- 디코더에 object query 를 넣으면 각 query 가 객체 하나를 뱉는다

object query 가 뭔지 모르겠다. 학습되는 벡터라고만 적혀 있는데, 디코더 입력 자리에 들어가는 것 같다. 개수는 100개로 고정.

여기서 막혔다. **디코더가 뭐였는지 기억이 안 난다.**

8주차에 배운 것 같은데 디코더 쪽은 시간 없어서 빨리 넘어갔던 기억만 있다. masked 어텐션이 들어간다고 적어뒀던 것 같은데 노트를 찾아야 한다. 3학년 1학기 딥러닝 폴더에 있을 텐데 몇 주차인지 모르겠다.

그리고 DETR 디코더는 masked 를 안 쓴다고 나온다. 순서가 없는 집합이라서. 그러면 8주차에 배운 디코더와 다른 건가? 아니면 masked 만 빼고 같은 건가?

bipartite matching

- 예측 100개와 정답을 일대일로 짝지어서 손실을 계산
- 헝가리안 알고리즘 쓴다고
- 이게 NMS 를 없애는 핵심인 듯. 중복 예측이 애초에 안 나오게 만든다

한계도 적혀 있다

- 학습이 오래 걸린다. 500 epoch
- 작은 객체에 약하다

발표까지 3일. 디코더부터 다시 잡아야 한다.
