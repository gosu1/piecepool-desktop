메모리 관리. 중간고사 범위 아님(1~4주차)인데 그냥 들음.

가상 메모리

- 프로세스마다 자기가 메모리 전체를 쓰는 것처럼 보이게 한다
- 실제 물리 메모리는 나눠 씀. 매핑은 OS 가
- 논리 주소 → 물리 주소 변환은 MMU 라는 하드웨어가

페이징

- 메모리를 고정 크기 조각(페이지)으로 나눔. 보통 4KB
- 페이지 테이블에 논리 페이지 → 물리 프레임 매핑
- 페이지 테이블 자체가 메모리에 있어서 접근이 두 번 → TLB 캐시로 줄임

페이지 폴트: 필요한 페이지가 메모리에 없으면 디스크에서 가져옴. 이게 엄청 느리다고. 이걸 최소화하는 게 다음 주 (페이지 교체 알고리즘).

프로세스가 스레드랑 달리 주소 공간이 따로인 게 이거였구나. 2주차에 "프로세스끼리는 IPC 써야 한다"고 했던 이유.

TLB 가 정확히 뭘 캐시하는지 헷갈림. 페이지 테이블 항목인 건 알겠는데 그러면 프로세스 바꿀 때마다 비워야 하나?
