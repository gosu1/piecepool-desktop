CPU 스케줄링. ready 큐에 있는 프로세스 중에 누구한테 CPU 를 줄 건가.

기준

- CPU 이용률, 처리량, 대기 시간, 응답 시간, 반환 시간
- 다 좋게 만들 수는 없고 트레이드오프

알고리즘

- FCFS: 온 순서대로. 긴 게 먼저 오면 뒤에 다 기다린다 (convoy effect)
- SJF: 짧은 것 먼저. 대기 시간이 최소. 근데 얼마나 걸릴지 미리 모른다는 게 문제
- 우선순위: 낮은 애는 영원히 못 받을 수 있다 (starvation) → aging 으로 해결
- 라운드 로빈: 시간 조각(time quantum)씩 돌아가면서. 너무 짧으면 컨텍스트 스위치만 하다 끝남

SJF 가 이론적으로 최적인데 실제로는 못 쓴다는 게 재밌었다. 다음 CPU 버스트를 예측해서 쓴다고 하는데 지수 평균 어쩌고. 슬라이드 22쪽 수식.

라운드 로빈 time quantum 은 보통 10~100ms 라고.

멀티레벨 큐 잠깐 나왔는데 시간 없어서 넘어감. 다음 주에 이어서 한다고.

과제 1 제출했다. 파이프 쪽에서 read 가 블로킹돼서 한참 헤맸다. 부모가 쓰기 끝을 안 닫아서 그런 거였다. 3시간 날림.
